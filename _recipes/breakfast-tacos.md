image: ""
recipeContent:
  prepTimeMinutes: 5
  cookTimeMinutes: 15
  servingsNumber: 4
  servingsUnit: Tacos
  ingredients:
    - { amount: "8", item: "small flour tortillas (6-inch), or corn tortillas" }
    - { amount: "12 oz", item: "chorizo sausage (or bacon)" }
    - { amount: "8", item: "large eggs" }
    - { amount: "1/4 cup", item: "milk" }
    - { amount: "1/4 tsp", item: "fine sea salt" }
    - { amount: "2 tbsp", item: "unsalted butter" }
    - { amount: "1 cup", item: "shredded cheddar or Mexican cheese blend" }
    - { amount: "1", item: "large avocado, diced" }
    - { amount: "1 cup", item: "salsa or pico de gallo" }
    - { amount: "To taste", item: "hot sauce" }
    - { amount: "To garnish", item: "cilantro" }
  steps:
    - "Heat the oven to 300°F. Wrap the tortillas in two foil stacks and warm them 15 minutes, keeping them in the foil until needed. (Toast corn tortillas in a dry cast-iron pan.)"
    - "Cook the chorizo in a large skillet over medium-high heat, breaking it up, until browned and cooked through. Drain on paper towels. (If using bacon, cook until crisp.)"
    - "Beat the eggs with the milk and salt."
    - "Melt the butter in a large nonstick skillet over medium-low heat. Pour in the eggs, let them set at the edges, then gently pull the cooked eggs toward the middle, folding without over-stirring."
    - "Take the pan off the heat while the eggs still look a little moist, since they finish cooking from the residual heat."
    - "Fill each tortilla with eggs and cheese, then add chorizo, avocado, salsa and hot sauce. Top with cilantro."
note: "Adapted from Natasha's Kitchen's breakfast tacos (5 stars from 15 votes, a small sample)."
