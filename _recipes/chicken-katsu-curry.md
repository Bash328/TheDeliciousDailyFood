  ingredients:
    - { amount: "1 tbsp", item: "vegetable oil" }
    - { amount: "10-12 oz", item: "onion, cut into 1-inch pieces" }
    - { amount: "1", item: "garlic clove, minced" }
    - { amount: "1 tbsp", item: "tomato paste" }
    - { amount: "1 tsp", item: "Worcestershire sauce (optional)" }
    - { amount: "2 tbsp", item: "curry powder (Madras)" }
    - { amount: "1 tsp", item: "salt" }
    - { amount: "1 tsp", item: "sugar" }
    - { amount: "8 oz", item: "potato, cut into 3/4-inch cubes" }
    - { amount: "8 oz", item: "carrots, cut into 3/4-inch pieces" }
    - { amount: "2 cups", item: "chicken stock" }
    - { amount: "1 tbsp", item: "cornstarch, mixed with 1 tbsp water" }
    - { amount: "1 tbsp", item: "salted butter" }
    - { amount: "2 lbs", item: "boneless, skinless chicken breast" }
    - { amount: "To taste", item: "salt and pepper" }
    - { amount: "2 tbsp", item: "all-purpose flour" }
    - { amount: "1", item: "egg, beaten" }
    - { amount: "1 1/3 cups", item: "panko breadcrumbs" }
    - { amount: "For frying", item: "vegetable oil" }
    - { amount: "6 cups", item: "steamed short-grain Japanese rice" }
  steps:
    - "Heat 1 tbsp oil in a Dutch oven over medium heat and cook the onion 2-3 minutes until translucent with browning edges."
    - "Add the garlic, tomato paste and Worcestershire for 1 minute, then stir in the curry powder, salt and sugar for 1 more minute."
    - "Add the potatoes, carrots and stock, bring to a simmer, cover and cook 20-25 minutes until tender."
    - "Meanwhile butterfly or pound the chicken to an even thickness, pat dry and season with salt and pepper. Dust lightly with flour, dip in the egg, then press into the panko."
    - "Heat a thin layer of oil in a skillet over medium heat until a panko crumb sizzles. Fry the chicken in batches, about 6 minutes on one side until golden, then 5-6 minutes on the other. Add oil as needed."
    - "Stir the cornstarch slurry into the curry until thickened, then stir in the butter and adjust the salt."
    - "Slice the chicken, set it over the rice and ladle the curry beside it."
note: "Adapted from The Woks of Life's chicken katsu curry rice (4.97 stars from 26 votes)."
