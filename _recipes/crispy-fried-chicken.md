description: "Buttermilk-brined chicken with a crunchy, well-seasoned crust."
image: ""
recipeContent:
  prepTimeMinutes: 20
  cookTimeMinutes: 25
  servingsNumber: 6
  servingsUnit: Servings
  ingredients:
    - { amount: "3 lbs", item: "bone-in chicken pieces" }
    - { amount: "2 cups", item: "buttermilk" }
    - { amount: "1 tbsp", item: "hot sauce" }
    - { amount: "2 cups", item: "all-purpose flour" }
    - { amount: "2 tsp", item: "paprika" }
    - { amount: "2 tsp", item: "garlic powder" }
    - { amount: "1 tsp", item: "onion powder" }
    - { amount: "1 tsp", item: "black pepper" }
    - { amount: "2 tsp", item: "salt" }
    - { amount: "1/2 tsp", item: "cayenne pepper" }
    - { amount: "For frying", item: "vegetable or peanut oil" }
  steps:
    - "Combine the chicken, buttermilk and hot sauce in a bowl or bag. Refrigerate at least 4 hours, or overnight."
    - "Whisk the flour, paprika, garlic powder, onion powder, pepper, salt and cayenne in a wide dish."
    - "Lift each piece out of the buttermilk, let the excess drip off, and press firmly into the flour mixture to coat."
    - "Heat 1 inch of oil in a deep skillet to 325°F."
    - "Fry the chicken in batches, turning every few minutes, 15-20 minutes total until deep golden and 165°F inside (175°F for thighs and drumsticks). If the crust browns before the inside is done, finish on a rack in a 325°F oven."
    - "Drain on a wire rack and rest 5 minutes before serving."
note: "Keep the oil between 300°F and 325°F, and use a thermometer inside the thickest part of each piece. Hotter and the crust burns before the chicken cooks through."
