---
title: "Beef and Barley Soup"
slug: beef-and-barley-soup
date: 2026-01-01
category: Soup
description: "A rich, hearty soup with tender beef, barley and vegetables."
image: ""
recipeContent:
  prepTimeMinutes: 20
  cookTimeMinutes: 90
  servingsNumber: 8
  servingsUnit: Bowls
  ingredients:
    - { amount: "1 1/2 lbs", item: "beef chuck, cut into small cubes" }
    - { amount: "1 tsp", item: "salt" }
    - { amount: "2 tbsp", item: "olive oil" }
    - { amount: "1", item: "onion, diced" }
    - { amount: "3", item: "carrots, sliced" }
    - { amount: "3", item: "celery stalks, sliced" }
    - { amount: "3", item: "garlic cloves, minced" }
    - { amount: "2 tbsp", item: "tomato paste" }
    - { amount: "8 cups", item: "beef broth" }
    - { amount: "1 tsp", item: "dried thyme" }
    - { amount: "2", item: "bay leaves" }
    - { amount: "1 cup", item: "pearl barley" }
  steps:
    - "Season the beef with salt and brown in the oil in batches in a large pot. Set aside."
    - "Cook the onion, carrots and celery 6 minutes. Add the garlic and tomato paste for 1 minute."
    - "Return the beef to the pot with the broth, thyme and bay leaves. Simmer, covered, 45 minutes."
    - "Add the barley and simmer 35-40 minutes more until the barley and beef are tender."
    - "Remove the bay leaves and adjust the seasoning."
note: "The soup thickens as it sits. Add broth when reheating."
