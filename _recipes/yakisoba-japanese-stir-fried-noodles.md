---
title: "Yakisoba (Japanese Stir-Fried Noodles)"
date: 2026-11-25
category: Lunch
cuisine: "Japanese"
description: "Chewy noodles stir-fried with pork belly, cabbage and vegetables in a tangy-sweet Worcestershire sauce."
image: ""
recipeContent:
  prepTimeMinutes: 10
  cookTimeMinutes: 20
  servingsNumber: 3
  servingsUnit: Servings
  ingredients:
    - { amount: "3 servings", item: "pre-steamed yakisoba noodles (one 16-17 oz pack)" }
    - { amount: "3/4 lb", item: "thinly sliced pork belly, cut into 2.5 cm pieces" }
    - { amount: "1/4 small head", item: "green cabbage, cut into bite-size pieces" }
    - { amount: "3", item: "shiitake mushrooms, sliced" }
    - { amount: "4 inches", item: "carrot, cut into matchsticks" }
    - { amount: "1/2", item: "yellow onion, sliced" }
    - { amount: "2", item: "green onions, cut into 5 cm pieces" }
    - { amount: "2 tbsp", item: "neutral oil, plus more if needed" }
    - { amount: "To taste", item: "black pepper" }
    - { amount: "1/4 cup", item: "Worcestershire sauce" }
    - { amount: "4 tsp", item: "oyster sauce" }
    - { amount: "4 tsp", item: "ketchup" }
    - { amount: "2 tsp", item: "soy sauce" }
    - { amount: "2 tsp", item: "sugar" }
    - { amount: "To serve", item: "aonori and pickled red ginger (optional)" }
  steps:
    - "Whisk the Worcestershire, oyster sauce, ketchup, soy sauce and sugar until the sugar dissolves. Taste; brands vary, so adjust."
    - "Heat the oil on a large griddle or pan over medium heat. Warm the noodle blocks on both sides, gently separating them with chopsticks as they loosen. Set aside."
    - "Add the pork in a single layer, season with pepper and stir-fry until no longer pink."
    - "Add the vegetables in stages, hardest first: onion for 1-2 minutes, then carrot for 1-2 minutes, then cabbage and mushrooms until starting to soften, then the green onion for a minute."
    - "Spread everything out, lay the noodles on top, pour over the sauce and toss with tongs until evenly coated and hot. Serve with aonori and pickled ginger if you have them."
note: "Adapted from Just One Cookbook's yakisoba (4.8 stars from 427 votes). Use a big pan; crowding steams the noodles instead of frying them."
