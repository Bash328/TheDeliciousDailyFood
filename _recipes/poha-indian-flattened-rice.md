---
title: "Poha (Indian Flattened Rice)"
date: 2026-11-25
category: Breakfast
cuisine: "Indian"
description: "A light, quick breakfast of softened rice flakes tossed with mustard seeds, curry leaves, onion, turmeric, crunchy peanuts and lemon."
image: ""
recipeContent:
  prepTimeMinutes: 10
  cookTimeMinutes: 15
  servingsNumber: 2
  servingsUnit: Servings
  ingredients:
    - { amount: "1 1/2 cups", item: "poha (medium or thick rice flakes)" }
    - { amount: "1 1/2 tbsp", item: "oil" }
    - { amount: "3-4 tbsp", item: "peanuts or cashews" }
    - { amount: "3/4 tsp", item: "mustard seeds" }
    - { amount: "3/4 tsp", item: "cumin seeds" }
    - { amount: "1 pinch", item: "hing (asafoetida)" }
    - { amount: "1 medium", item: "onion, finely chopped" }
    - { amount: "1 sprig", item: "curry leaves" }
    - { amount: "2-3", item: "green chilies, slit or chopped" }
    - { amount: "1 medium", item: "potato, cut into 1 cm cubes (optional)" }
    - { amount: "1/4 tsp", item: "turmeric" }
    - { amount: "1/3 tsp", item: "salt, to taste" }
    - { amount: "1/2-1 tsp", item: "sugar (optional)" }
    - { amount: "To taste", item: "lemon juice" }
    - { amount: "2 tbsp", item: "cilantro, chopped" }
  steps:
    - "Rinse the poha quickly in a strainer under plenty of water, twice, and drain well. Cover and leave to soften; a flake should crush easily between your fingers. If not, sprinkle with a little water. Mix in the salt and sugar, breaking up lumps."
    - "Fry the peanuts in the oil over medium heat until golden and crunchy, then lift them out."
    - "Add the mustard and cumin seeds to the same oil. When they pop, add the hing, onion, curry leaves and chilies and cook until the onion turns lightly pink."
    - "If using potato, add it now, cover and cook on low until tender, sprinkling with water if needed."
    - "Stir in the turmeric and poha, cover and steam on very low heat until hot and soft."
    - "Take off the heat, check the salt, squeeze over lemon juice and top with cilantro and the peanuts."
note: "Adapted from Indian Healthy Recipes' poha (5 stars from 301 votes). Use thick or medium flakes; thin ones turn mushy."
