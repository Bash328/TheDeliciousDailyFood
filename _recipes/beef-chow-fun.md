recipeContent:
  prepTimeMinutes: 45
  cookTimeMinutes: 5
  servingsNumber: 4
  servingsUnit: Servings
  ingredients:
    - { amount: "10 oz (285 g)", item: "flank steak, sliced 3 mm thick" }
    - { amount: "1 1/2 tbsp", item: "water" }
    - { amount: "1/4 tsp", item: "baking soda (optional)" }
    - { amount: "1 tsp", item: "cornstarch" }
    - { amount: "2 tsp", item: "oyster sauce" }
    - { amount: "2 tsp + 2 tbsp", item: "Shaoxing wine, divided" }
    - { amount: "1 tsp + 2 tbsp", item: "soy sauce, divided" }
    - { amount: "12 oz", item: "fresh wide rice noodles" }
    - { amount: "3 tbsp", item: "vegetable oil, divided" }
    - { amount: "3 thin slices", item: "ginger" }
    - { amount: "4", item: "scallions, halved lengthwise and cut into 7 cm pieces" }
    - { amount: "2 tsp", item: "dark soy sauce" }
    - { amount: "1/2 tsp", item: "sesame oil" }
    - { amount: "1/4 tsp", item: "sugar" }
    - { amount: "To taste", item: "salt and white pepper" }
    - { amount: "4-6 oz", item: "fresh mung bean sprouts" }
  steps:
    - "Mix the beef with the water, baking soda, cornstarch, oyster sauce, 2 tsp Shaoxing wine and 1 tsp soy sauce. Marinate at least 30 minutes."
    - "If the noodles are in sheets, cut them 2.5 cm wide. If they're stiff, blanch them for 30 seconds in boiling water, cool in ice water and drain well."
    - "Heat a wok until smoking, add 1 1/2 tbsp oil and sear the beef until browned. Set aside."
    - "Add the remaining oil, the ginger for 15 seconds, then the scallions. Spread in the noodles and stir-fry 15 seconds, then splash the 2 tbsp Shaoxing wine around the edge of the wok."
    - "Add the 2 tbsp soy sauce, dark soy, sesame oil, sugar and the beef. Toss, lifting the noodles from the bottom, until evenly coated."
    - "Season with salt and white pepper, add the bean sprouts and toss until just tender. Serve straight away."
note: "Adapted from The Woks of Life's beef chow fun (4.95 stars from 106 votes). The 45 minutes of prep is mostly marinating. The hotter the wok, the better."
