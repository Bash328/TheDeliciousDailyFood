title: "Loaded Baked Potato Soup"
slug: potato-soup
date: 2026-06-08
category: Soup
tag: "Comfort Food"
description: "Everything a loaded baked potato has, in soup form, plus the leftover bacon fat doing the work of building flavor."
image: ""
prepTimeMinutes: 15
cookTimeMinutes: 30
servingsNumber: 6
servingsUnit: Servings
ingredients:
  - { amount: "6 slices", item: "bacon, chopped" }
  - { amount: "1", item: "yellow onion, diced" }
  - { amount: "3", item: "garlic cloves, minced" }
  - { amount: "1/3 cup", item: "all-purpose flour" }
  - { amount: "4 cups", item: "chicken broth" }
  - { amount: "2 cups", item: "whole milk" }
  - { amount: "2 lbs", item: "russet potatoes, peeled and cubed" }
  - { amount: "1 cup", item: "shredded cheddar, plus extra for topping" }
  - { amount: "1/2 cup", item: "sour cream" }
  - { amount: "1/4 cup", item: "chives, chopped" }
steps:
  - "Cook the bacon in a large pot until crisp. Remove with a slotted spoon, leaving the fat behind."
  - "Add onion to the bacon fat and cook 5 minutes until soft. Add garlic and cook 30 seconds more."
  - "Sprinkle in the flour and stir constantly for a minute to cook out the raw taste."
  - "Slowly whisk in the broth and milk, then add the potatoes. Bring to a simmer and cook 20 minutes until the potatoes are tender."
  - "Mash some of the potatoes right in the pot for thickness, leaving the rest chunky. Stir in cheddar and sour cream until melted and smooth."
  - "Ladle into bowls and top with the reserved bacon, extra cheddar, and chives."
note: "Thin leftovers with a splash of broth when reheating — it thickens in the fridge."
