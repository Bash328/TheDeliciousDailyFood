title: "Lomo Saltado"

date: 2026-01-01
category: Dinner
cuisine: "Peruvian"
description: "Quick wok-seared steak with onions, tomatoes and french fries in a soy, lime and aji amarillo sauce."
image: ""
recipeContent:
  prepTimeMinutes: 10
  cookTimeMinutes: 10
  servingsNumber: 4
  servingsUnit: Servings
  ingredients:
    - { amount: "1 lb", item: "sirloin steak, cut into strips" }
    - { amount: "1/2 tbsp", item: "salt" }
    - { amount: "1/2 tbsp", item: "black pepper" }
    - { amount: "2 tbsp", item: "soy sauce" }
    - { amount: "2 tbsp", item: "rice vinegar" }
    - { amount: "2 tbsp", item: "aji amarillo paste" }
    - { amount: "1", item: "lime, juiced" }
    - { amount: "1", item: "garlic clove, grated" }
    - { amount: "3 tbsp", item: "chopped parsley, divided" }
    - { amount: "2 tbsp", item: "canola or vegetable oil" }
    - { amount: "2", item: "tomatoes, sliced" }
    - { amount: "1", item: "red onion, cut into wedges" }
    - { amount: "3 cups", item: "cooked french fries" }
    - { amount: "To serve", item: "cooked rice and lime wedges" }
  steps:
    - "Season the beef with the salt and pepper."
    - "Whisk the soy sauce, vinegar, aji amarillo paste, lime juice, garlic and 2 tbsp of the parsley. Massage it into the beef and marinate while you prep, or up to 8 hours."
    - "Heat the oil in a wok over medium-high heat until it just starts to smoke. Lift the beef out of the marinade (keep it) and sear about 1 minute until deeply browned. Remove."
    - "Lower the heat to medium and cook the onion in the leftover marinade until slightly softened. Add the tomatoes until soft, then return the beef and any marinade."
    - "Toss in the fries to coat in the sauce and heat everything through."
    - "Serve over rice with the remaining parsley and a squeeze of lime."
note: "Adapted from Tasting Table's lomo saltado (5 stars from 33 ratings). Aji amarillo paste is what makes it taste Peruvian; look for it in Latin grocers."
