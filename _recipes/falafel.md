  prepTimeMinutes: 45

  servingsNumber: 4
  servingsUnit: Falafel
  ingredients:
    - { amount: "1 cup", item: "dried chickpeas, soaked overnight (not canned)" }
    - { amount: "1/2 cup", item: "onion, roughly chopped" }
    - { amount: "1 cup", item: "fresh parsley, roughly chopped" }
    - { amount: "1 cup", item: "fresh cilantro, roughly chopped" }
    - { amount: "1", item: "small green chile pepper (serrano or jalapeño)" }
    - { amount: "3", item: "garlic cloves" }
    - { amount: "1 tsp", item: "cumin" }
    - { amount: "1 tsp", item: "salt" }
    - { amount: "1/2 tsp", item: "cardamom" }
    - { amount: "1/4 tsp", item: "black pepper" }
    - { amount: "2 tbsp", item: "chickpea flour (or other flour)" }
    - { amount: "1/2 tsp", item: "baking soda" }
    - { amount: "For frying", item: "oil, about 3 inches deep" }
    - { amount: "To serve", item: "tahini sauce" }
  steps:
    - "Soak the dried chickpeas in plenty of cold water for 8-12 hours (they triple in size), then drain and rinse."
    - "Pulse the chickpeas, onion, parsley, cilantro, chile, garlic and spices in a food processor until the mixture looks like coarse crumbs. Don't blend it smooth."
    - "Stir in the chickpea flour and baking soda and chill 30-60 minutes."
    - "Shape into 18 balls or patties with your hands or a scoop. If the mixture is too wet, add a tablespoon of flour. If it crumbles, add a teaspoon or two of water."
    - "Heat 3 inches of oil to 350°F and fry in batches of 6-8 for 1-2 minutes until golden (the source page also gives a baked option)."
    - "Drain on paper towels and serve warm with tahini sauce."
note: "Adapted from Downshiftology's falafel (4.94 stars from 520 votes). Canned chickpeas make the mix too wet, so use dried ones."
