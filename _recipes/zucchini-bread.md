---
title: "Zucchini Bread"
date: 2026-11-25
category: Breakfast
cuisine: "American"
description: "A moist, lightly spiced quick bread with cinnamon and nutmeg. Add chocolate chips or nuts if you like."
image: ""
recipeContent:
  prepTimeMinutes: 10
  cookTimeMinutes: 55
  servingsNumber: 10
  servingsUnit: Slices
  ingredients:
    - { amount: "1 3/4 cups (220 g)", item: "all-purpose flour" }
    - { amount: "1 tsp", item: "baking powder" }
    - { amount: "1/2 tsp", item: "baking soda" }
    - { amount: "1/2 tsp", item: "salt" }
    - { amount: "1 1/2 tsp", item: "ground cinnamon" }
    - { amount: "1/4 tsp", item: "ground nutmeg" }
    - { amount: "1/2 cup (120 ml)", item: "vegetable oil" }
    - { amount: "1/2 cup (100 g)", item: "packed brown sugar" }
    - { amount: "1/2 cup (100 g)", item: "granulated sugar" }
    - { amount: "2 large", item: "eggs, at room temperature" }
    - { amount: "1/4 cup (60 g)", item: "unsweetened applesauce, sour cream or Greek yogurt" }
    - { amount: "2 tsp", item: "vanilla extract" }
    - { amount: "1 1/2 cups (180 g)", item: "shredded zucchini (no need to squeeze)" }
    - { amount: "1 cup", item: "chocolate chips or chopped nuts (optional)" }
  steps:
    - "Heat the oven to 180°C / 350°F and grease a 9x5-inch loaf pan."
    - "Whisk the flour, baking powder, baking soda, salt, cinnamon and nutmeg in a large bowl."
    - "In another bowl whisk the oil, both sugars, eggs, applesauce and vanilla, then stir in the zucchini."
    - "Pour the wet mix into the dry and stir just until combined; don't overmix. Fold in any add-ins."
    - "Spread in the pan and bake 55-70 minutes, until a toothpick in the middle comes out with no wet batter. Cover loosely with foil halfway if the top browns fast."
    - "Cool in the pan for an hour, then on a rack before slicing neatly."
note: "Adapted from Sally's Baking Addiction's zucchini bread (4.9 stars from 596 votes). Keeps 3-4 days at room temperature, or a week in the fridge."
