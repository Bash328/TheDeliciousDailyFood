---
title: "Hearty Beef Stew"
slug: hearty-beef-stew
date: 2026-01-01
category: Dinner
description: "Tender chunks of beef, potatoes and carrots in a rich, glossy gravy."
image: ""
recipeContent:
  prepTimeMinutes: 25
  cookTimeMinutes: 150
  servingsNumber: 6
  servingsUnit: Servings
  ingredients:
    - { amount: "2 lbs", item: "beef chuck, cut into 1-inch cubes" }
    - { amount: "1 tsp", item: "salt" }
    - { amount: "1/2 tsp", item: "black pepper" }
    - { amount: "3 tbsp", item: "all-purpose flour" }
    - { amount: "3 tbsp", item: "olive oil" }
    - { amount: "1", item: "large onion, chopped" }
    - { amount: "3", item: "garlic cloves, minced" }
    - { amount: "2 tbsp", item: "tomato paste" }
    - { amount: "4 cups", item: "beef broth" }
    - { amount: "2", item: "bay leaves" }
    - { amount: "1 tsp", item: "dried thyme" }
    - { amount: "1 lb", item: "baby potatoes, halved" }
    - { amount: "4", item: "carrots, cut into chunks" }
    - { amount: "1 cup", item: "frozen peas" }
  steps:
    - "Toss the beef with salt, pepper and flour until coated."
    - "Heat the oil in a Dutch oven over medium-high heat. Brown the beef in batches, 2 minutes per side, and set aside."
    - "Cook the onion in the same pot for 5 minutes. Add the garlic and tomato paste and stir for 1 minute."
    - "Return the beef to the pot with the broth, bay leaves and thyme. Scrape up the browned bits, bring to a simmer, cover and cook on low for 1 hour 15 minutes."
    - "Add the potatoes and carrots and cook, covered, 45 minutes more until the beef and vegetables are tender."
    - "Stir in the peas, cook 5 minutes, remove the bay leaves and serve."
note: "Chuck is the right cut here: it turns tender after a long simmer, while leaner cuts go dry."
---
