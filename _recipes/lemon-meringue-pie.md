recipeContent:
  prepTimeMinutes: 40
  cookTimeMinutes: 70
  servingsNumber: 8
  servingsUnit: Slices
  ingredients:
    - { amount: "1", item: "blind-baked 9-inch pie crust (homemade or store-bought)" }
    - { amount: "5", item: "large egg yolks (save the whites for the meringue)" }
    - { amount: "1 1/3 cups", item: "water" }
    - { amount: "1 cup", item: "granulated sugar" }
    - { amount: "1/3 cup", item: "cornstarch" }
    - { amount: "1/4 tsp", item: "salt" }
    - { amount: "1/2 cup", item: "fresh lemon juice" }
    - { amount: "1 tbsp", item: "lemon zest" }
    - { amount: "2 tbsp", item: "unsalted butter, softened" }
    - { amount: "5", item: "large egg whites, room temperature" }
    - { amount: "1/2 tsp", item: "cream of tartar" }
    - { amount: "1/2 cup", item: "granulated sugar, for the meringue" }
    - { amount: "1/8 tsp", item: "salt, for the meringue" }
  steps:
    - "Heat the oven to 350°F with a rack on the lowest shelf, and have the crust blind-baked."
    - "Whisk the egg yolks in a bowl. In a saucepan, whisk the water, sugar, cornstarch, salt, lemon juice and zest over medium heat, about 6 minutes, until it thickens and bubbles."
    - "Slowly stream a few spoonfuls of the hot mixture into the yolks, then whisk the yolks back into the pan in a slow stream. Cook on medium until very thick with big bubbles breaking the surface. Off the heat, whisk in the butter, and pour into the warm crust."
    - "Beat the egg whites with the cream of tartar on medium for 1 minute, then on high until soft peaks form, about 4 minutes. Add the sugar and salt and beat until glossy stiff peaks form, about 2 more minutes."
    - "Spread the meringue over the hot filling, sealing it to the edge of the crust all the way round, and swirl into peaks."
    - "Bake on the lowest rack 20-25 minutes until golden, tenting with foil if it browns too fast."
    - "Cool 1 hour at room temperature, then chill until fully set before slicing. It's best on the first day."
note: "Adapted from Sally's Baking Addiction's classic lemon meringue pie (4.8 stars from 470 votes). The meringue weeps over time, so serve it the day you make it."
