ingredients:
  - { amount: "2", item: "medium potatoes, boiled and mashed" }
  - { amount: "1/2 cup", item: "shredded cabbage" }
  - { amount: "1/4 cup", item: "grated carrot" }
  - { amount: "1/4 cup", item: "frozen peas, thawed" }
  - { amount: "1/2", item: "small onion, finely chopped" }
  - { amount: "1", item: "green chile, finely chopped (optional)" }
  - { amount: "2 tbsp", item: "fresh cilantro, chopped, plus more to serve" }
  - { amount: "1 tsp", item: "chaat masala" }
  - { amount: "1/2 tsp", item: "ground cumin" }
  - { amount: "", item: "Salt, to taste" }
  - { amount: "8", item: "slices white sandwich bread" }
  - { amount: "4 tbsp", item: "green chutney (mint-cilantro), or store-bought" }
  - { amount: "1 cup", item: "shredded cheddar cheese" }
  - { amount: "3 tbsp", item: "butter, softened" }
  - { amount: "1/4 cup", item: "sour cream or yogurt, thinned with a splash of water" }
  - { amount: "", item: "Chili flakes, for serving" }
steps:
  - "In a bowl, mix the mashed potato with the cabbage, carrot, peas, onion, chile, cilantro, chaat masala, cumin, and a pinch of salt."
  - "Spread one side of each bread slice with green chutney. Divide the vegetable filling and cheese between four slices, and top with the remaining bread, chutney-side down."
  - "Butter the outsides of the sandwiches. Toast in a hot skillet or panini press 3-4 minutes per side, pressing down, until deeply golden and crisp and the cheese has melted."
  - "Slice each sandwich into triangles and stack on a plate."
  - "Drizzle with the thinned sour cream, scatter with cilantro and chili flakes, and serve hot."
note: "A panini press or sandwich toaster gets the crispiest, most even crust — a skillet with a heavy pan pressed on top works nearly as well."
