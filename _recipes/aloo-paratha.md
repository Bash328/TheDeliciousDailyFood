---
title: "Aloo Paratha (Potato Stuffed Flatbread)"
date: 2026-11-25
category: Breakfast
cuisine: "Indian"
description: "Whole wheat flatbreads stuffed with spiced mashed potato and griddled in ghee until golden. Serve with yogurt and pickle."
image: ""
recipeContent:
  prepTimeMinutes: 20
  cookTimeMinutes: 25
  servingsNumber: 8
  servingsUnit: Parathas
  ingredients:
    - { amount: "2 cups (240 g)", item: "whole wheat flour (atta), plus more for rolling" }
    - { amount: "1/4 tsp", item: "salt" }
    - { amount: "1 tbsp", item: "oil (optional)" }
    - { amount: "About 3/4 cup", item: "water, for the dough" }
    - { amount: "350 g (3 medium)", item: "potatoes" }
    - { amount: "1", item: "green chili, chopped (optional)" }
    - { amount: "3/4 tsp", item: "ginger, grated" }
    - { amount: "2 tbsp", item: "cilantro, very finely chopped" }
    - { amount: "1/2 tsp", item: "salt, to taste" }
    - { amount: "1/2-3/4 tsp", item: "garam masala" }
    - { amount: "1/2 tsp", item: "Kashmiri red chili powder" }
    - { amount: "3/4-1 tsp", item: "coriander powder" }
    - { amount: "1/2 tsp", item: "chaat masala (or 1 tbsp lemon juice)" }
    - { amount: "1 tsp", item: "kasuri methi, crushed" }
    - { amount: "4 tbsp", item: "ghee or oil, for cooking" }
    - { amount: "To serve", item: "butter, yogurt and pickle" }
  steps:
    - "Boil the potatoes just until fork-tender, not mushy."
    - "Meanwhile mix the flour, salt and oil, and add water a little at a time to make a soft, non-sticky dough. Knead until it dents easily when pressed, then cover and rest."
    - "Peel the potatoes while warm and grate or mash until there are no lumps; lumps tear the parathas. Mix in the chili, ginger, cilantro, salt and all the spices, and taste."
    - "Divide the dough and filling into 8 portions each. Roll a dough ball into a 10 cm round, put a portion of filling in the middle, and bring the edges up over it, pinching to seal."
    - "Flatten gently, dust with flour and roll out, sealed side down, to about 20 cm. Turn it a little every few rolls so it doesn't stick or tear."
    - "Cook on a hot griddle until bubbles appear, 2-3 minutes, then flip. Brush with ghee, flip again and press the edges until golden spots appear on both sides. Stack to keep soft and serve with butter, yogurt and pickle."
note: "Adapted from Indian Healthy Recipes' aloo paratha (5 stars from 216 votes)."
