recipeContent:
  prepTimeMinutes: 60
  cookTimeMinutes: 20
  servingsNumber: 52
  servingsUnit: Gyoza
  ingredients:
    - { amount: "1/2 lb", item: "ground pork" }
    - { amount: "3/4 lb", item: "green cabbage (1/4 large head)" }
    - { amount: "1 tsp", item: "kosher salt, for the cabbage" }
    - { amount: "2", item: "shiitake mushrooms" }
    - { amount: "2", item: "green onions" }
    - { amount: "1 tsp", item: "grated fresh ginger, with juice" }
    - { amount: "2", item: "garlic cloves" }
    - { amount: "2 tsp", item: "sake (optional)" }
    - { amount: "2 tsp", item: "toasted sesame oil" }
    - { amount: "2 tsp", item: "soy sauce" }
    - { amount: "1/8 tsp", item: "freshly ground black pepper" }
    - { amount: "1 package", item: "gyoza wrappers" }
    - { amount: "For sealing", item: "water" }
    - { amount: "1 tbsp", item: "neutral oil, for cooking" }
    - { amount: "1 tsp", item: "toasted sesame oil, to finish" }
    - { amount: "4 tbsp", item: "water, for steaming" }
    - { amount: "1 tbsp", item: "soy sauce, for dipping" }
    - { amount: "1 tbsp", item: "rice vinegar, for dipping" }
    - { amount: "1/8 tsp", item: "la-yu (chili oil), optional" }
  steps:
    - "Cut the core from the cabbage, slice the leaves and chop very finely. Toss with 1 tsp salt and let it wilt, then squeeze out all the water."
    - "Mince the green onions and mushroom caps. Mix the pork with the green onions, mushrooms, sake, sesame oil, soy sauce, pepper, ginger and garlic, then knead in the squeezed cabbage until uniform."
    - "Keep the wrappers covered with a damp towel. Put a level tablespoon of filling in the center of a wrapper, fold it in half and pleat the edge on both sides, pressing to seal. Set the gyoza upright on a lined tray."
    - "Heat a large nonstick pan over medium heat with 1 tbsp oil. Place the gyoza flat-side down in a single layer, not touching, and cook about 3 minutes until the bottoms are golden."
    - "Add 4 tbsp water, cover immediately and steam about 3 minutes until most of the water is gone."
    - "Uncover and cook about 1 minute until the water is gone, drizzle with 1 tsp sesame oil and cook until the bottoms are deep golden and crisp."
    - "Mix the dipping sauce for each serving: 1 tbsp rice vinegar, 1 tbsp soy sauce and optional chili oil. Serve hot."
note: "Adapted from Just One Cookbook's gyoza (4.69 stars from 506 votes). The recipe makes about 52, and they freeze well: freeze them uncooked, then steam 1-2 minutes longer."
