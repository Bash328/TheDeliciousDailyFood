---
title: "Lamb Shanks Massaman Curry"
date: 2026-11-25
category: Dinner
cuisine: "Thai"
description: "Lamb shanks baked slowly in massaman curry and coconut milk with potatoes, star anise and cinnamon until falling off the bone."
image: ""
recipeContent:
  prepTimeMinutes: 5
  cookTimeMinutes: 180
  servingsNumber: 5
  servingsUnit: Servings
  ingredients:
    - { amount: "1.5 kg (3 lb)", item: "lamb shanks (4-5 medium)" }
    - { amount: "114 g (4 oz) can", item: "massaman curry paste (Maesri is a good brand)" }
    - { amount: "400 ml (14 oz)", item: "full-fat coconut milk" }
    - { amount: "2 cups", item: "low-sodium chicken broth" }
    - { amount: "1", item: "onion, halved and sliced 1 cm thick" }
    - { amount: "400 g (14 oz)", item: "small potatoes, halved if large" }
    - { amount: "1", item: "star anise" }
    - { amount: "1", item: "cinnamon stick" }
    - { amount: "To serve", item: "sliced red chili, cilantro and jasmine rice" }
  steps:
    - "Heat the oven to 180°C / 350°F (160°C fan)."
    - "Mix the curry paste, coconut milk and broth in a 9x13-inch glass or ceramic baking dish. Add the onion, potatoes, star anise, cinnamon and lamb, and turn the shanks to coat. Cover tightly with foil."
    - "Bake 2 hours. Uncover and bake another 1-1 1/2 hours, depending on the size of the shanks, turning them twice, until the meat pulls apart easily with two forks."
    - "Lift out the lamb, tilt the dish and skim off the excess fat, then stir the sauce; it should be thick and syrupy."
    - "Serve the shanks with the sauce over jasmine rice, scattered with chili and cilantro."
note: "Adapted from RecipeTin Eats' lamb shanks massaman curry (4.96 stars from 270 votes). Nearly all hands-off oven time."
