  ingredients:
    - { amount: "1.4 lbs", item: "beef chuck, cut into 2.5-inch cubes" }
    - { amount: "2 cups", item: "low-sodium beef broth" }
    - { amount: "2", item: "bay leaves" }
    - { amount: "1", item: "lemongrass stalk (trimmings go in the beef pot, the white part goes in the paste)" }
    - { amount: "6", item: "dried red chilies, seeded" }
    - { amount: "4", item: "shallots, peeled" }
    - { amount: "5", item: "garlic cloves, unpeeled" }
    - { amount: "1 1/4 inch", item: "piece galangal" }
    - { amount: "4-6 tbsp", item: "water" }
    - { amount: "1/2 tsp", item: "ground cloves" }
    - { amount: "3/4 tsp", item: "ground cumin" }
    - { amount: "1/8 tsp", item: "ground nutmeg" }
    - { amount: "3/4 tsp", item: "ground coriander" }
    - { amount: "1/2 tsp", item: "ground cardamom" }
    - { amount: "1/2 tsp", item: "ground cinnamon" }
    - { amount: "1/4 cup", item: "vegetable oil" }
    - { amount: "14 oz", item: "full-fat coconut milk" }
    - { amount: "1", item: "cinnamon stick" }
    - { amount: "1", item: "star anise" }
    - { amount: "1 tsp", item: "tamarind paste" }
    - { amount: "1 tbsp", item: "fish sauce" }
    - { amount: "1 tbsp", item: "white sugar" }
    - { amount: "2", item: "small potatoes, peeled and cut into 1-inch pieces" }
    - { amount: "3 tbsp", item: "roughly chopped peanuts" }
    - { amount: "To serve", item: "jasmine rice, fried shallots and sliced red chili (optional)" }
  steps:
    - "Trim the lemongrass, keeping the trimmings, and finely chop the white part for the paste."
    - "Put the beef, broth, bay leaves and lemongrass trimmings in a saucepan (the liquid should almost cover the beef). Bring to a boil, then simmer gently 1 1/2-2 hours until fork-tender. Lift out the beef and reduce the liquid to about 1 1/2 cups."
    - "Char the shallots, garlic and galangal in a dry smoking-hot skillet about 1 1/2 minutes, then char the dried chilies 10 seconds per side. When cool, grate the galangal, peel the garlic and shake the seeds from the chilies."
    - "Toast the ground spices in a dry pan about 30 seconds until fragrant, then tip into a bowl."
    - "Blitz the chilies, then add the galangal, chopped lemongrass, charred shallots and garlic, toasted spices and 4 tbsp water and blend to a smooth paste, adding water as needed."
    - "Heat the oil over medium-high heat and cook the paste 3 minutes until thick and fragrant."
    - "Stir in the coconut milk, cinnamon stick, star anise and the reserved braising liquid and simmer 3 minutes. Add the fish sauce, tamarind and sugar."
    - "Add the potatoes and cook about 7 minutes until tender, then add the beef and simmer 2 minutes until the sauce thickens."
    - "Taste for balance (it should be sweet, salty and a little sour) and serve over rice with the peanuts, which are essential."
note: "Adapted from RecipeTin Eats' massaman curry (4.94 stars from 188 votes). It's a project, but the paste and braise can be done a day ahead."
