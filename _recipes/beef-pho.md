cuisine: "Vietnamese"
description: "A fragrant, slow-simmered beef broth with charred ginger and onion, rice noodles and rare beef."
image: ""
recipeContent:
  prepTimeMinutes: 20
  cookTimeMinutes: 180
  servingsNumber: 6
  servingsUnit: Bowls
  ingredients:
    - { amount: "2", item: "large onions, halved" }
    - { amount: "5 oz", item: "ginger, sliced lengthwise" }
    - { amount: "10", item: "star anise" }
    - { amount: "4", item: "cinnamon sticks" }
    - { amount: "4", item: "cardamom pods" }
    - { amount: "3", item: "cloves" }
    - { amount: "1 1/2 tbsp", item: "coriander seeds" }
    - { amount: "3 lbs", item: "beef brisket" }
    - { amount: "2 lbs", item: "meaty beef bones" }
    - { amount: "2 lbs", item: "marrow bones (leg or knuckle), cut to expose the marrow" }
    - { amount: "15 cups (3.5 L)", item: "water" }
    - { amount: "2 tbsp", item: "white sugar" }
    - { amount: "1 tbsp", item: "salt" }
    - { amount: "3 tbsp", item: "fish sauce" }
    - { amount: "1 3/4 oz", item: "dried rice sticks (or 4 oz fresh)" }
    - { amount: "1 oz", item: "raw beef tenderloin, very thinly sliced" }
    - { amount: "To serve", item: "bean sprouts, Thai basil, cilantro, lime wedges, sliced red chili, hoisin and sriracha" }
  steps:
    - "Char the onion and ginger, cut side down, in a dry skillet over high heat until blackened in spots, then turn. Toast the spices in a dry pan for 3 minutes."
    - "Put the bones and brisket in a large pot, cover with water, boil 5 minutes, then drain and rinse everything under the tap."
    - "Wipe the pot, bring the 15 cups of water to a boil and add the bones, brisket, onion, ginger, spices, sugar and salt."
    - "Cover and simmer 3 hours. Lift out the brisket (it should be fall-apart tender), cool and refrigerate."
    - "Simmer the broth uncovered 40 minutes more, then strain, discarding the bones and spices. You want about 10 cups."
    - "Add the fish sauce and adjust the salt and sugar. The broth should be beefy, fragrant, savory and just barely sweet."
    - "Cook the noodles per the package. Put them in bowls, top with the raw tenderloin and slices of the cooked brisket, then ladle over hot broth to cook the beef."
    - "Serve with bean sprouts, herbs, lime, chili, hoisin and sriracha."
note: "Adapted from RecipeTin Eats' Vietnamese pho (4.99 stars from 134 votes). The broth takes time but is mostly hands-off, and it freezes well."
