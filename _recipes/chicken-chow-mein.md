title: "Chicken Chow Mein"
date: 2026-11-25
category: Dinner
cuisine: "Chinese"
description: "Takeout-style chow mein in 15 minutes: noodles, chicken, cabbage and bean sprouts tossed in a savory oyster sauce."
image: ""
recipeContent:
  prepTimeMinutes: 10
  cookTimeMinutes: 5
  servingsNumber: 2
  servingsUnit: Servings
  ingredients:
    - { amount: "200 g (6 oz)", item: "chicken breast or thigh, thinly sliced" }
    - { amount: "200 g (6 oz)", item: "chow mein noodles" }
    - { amount: "1 1/2 tbsp", item: "peanut or vegetable oil" }
    - { amount: "2", item: "garlic cloves, finely chopped" }
    - { amount: "4 cups", item: "green cabbage, finely shredded" }
    - { amount: "1", item: "carrot, cut into matchsticks" }
    - { amount: "1 1/2 cups", item: "bean sprouts" }
    - { amount: "3", item: "green onions, cut into 5 cm pieces, white and green parts kept apart" }
    - { amount: "2 tsp", item: "cornstarch" }
    - { amount: "1 1/2 tbsp", item: "soy sauce" }
    - { amount: "1 1/2 tbsp", item: "oyster sauce" }
    - { amount: "1 1/2 tbsp", item: "Shaoxing wine (or mirin)" }
    - { amount: "2 tsp", item: "sugar (1 tsp if using mirin)" }
    - { amount: "1/2 tsp", item: "sesame oil" }
    - { amount: "Pinch", item: "white pepper" }
    - { amount: "1/4 cup", item: "water" }
  steps:
    - "Sauce: stir the cornstarch into the soy sauce until smooth, then mix in the oyster sauce, Shaoxing wine, sugar, sesame oil and white pepper."
    - "Toss the chicken with 1 tbsp of the sauce and leave 10 minutes. Prepare the noodles as the packet says and drain."
    - "Heat the oil in a wok over high heat. Fry the garlic for 10 seconds, until just golden, then add the chicken and stir-fry about a minute, until lightly browned outside."
    - "Add the cabbage, carrot and the white parts of the green onions and stir-fry 1 1/2 minutes, until the cabbage mostly wilts."
    - "Add the noodles, the rest of the sauce and the water and toss constantly for a minute."
    - "Add the bean sprouts and green onion tops, toss 30 seconds until the sprouts just wilt, and serve straight away."
note: "Adapted from RecipeTin Eats' chow mein (4.97 stars from 359 votes). Works with beef, pork or shrimp too."
