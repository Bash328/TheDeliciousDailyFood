description: "Soft, herby meatballs simmered in a simple tomato sauce."
image: ""
recipeContent:
  prepTimeMinutes: 25
  cookTimeMinutes: 40
  servingsNumber: 6
  servingsUnit: Servings
  ingredients:
    - { amount: "1 lb", item: "ground beef" }
    - { amount: "1/2 lb", item: "ground pork" }
    - { amount: "1/2 cup", item: "breadcrumbs" }
    - { amount: "1/2 cup", item: "grated Parmesan" }
    - { amount: "2", item: "eggs" }
    - { amount: "3", item: "garlic cloves, minced" }
    - { amount: "1/4 cup", item: "fresh parsley, chopped" }
    - { amount: "1 tsp", item: "salt" }
    - { amount: "2 tbsp", item: "olive oil" }
    - { amount: "1", item: "small onion, diced" }
    - { amount: "1 can (28 oz)", item: "crushed tomatoes" }
    - { amount: "1 tsp", item: "dried oregano" }
    - { amount: "1 lb", item: "spaghetti" }
  steps:
    - "Mix the beef, pork, breadcrumbs, Parmesan, eggs, half the garlic, parsley and salt gently. Roll into 18 golf-ball-sized meatballs."
    - "Brown the meatballs in the oil in a large pot over medium-high heat, 6 minutes total. Set aside."
    - "In the same pot, cook the onion 4 minutes, add the remaining garlic for 30 seconds, then add the tomatoes, oregano and a pinch of salt."
    - "Return the meatballs to the sauce, cover and simmer on low 25 minutes."
    - "Cook the spaghetti until al dente and drain. Serve topped with meatballs, sauce and extra Parmesan."
note: "The pork keeps the meatballs tender. You can use all beef if that's what you have."
