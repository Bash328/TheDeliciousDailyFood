title: "Thai Basil Chicken (Pad Kra Pao)"
date: 2026-11-25
category: Dinner
cuisine: "Thai"
description: "Garlicky, chili-hot chicken stir-fried with Thai basil in a glossy oyster and soy sauce. Fifteen minutes, start to finish."
image: ""
recipeContent:
  prepTimeMinutes: 10
  cookTimeMinutes: 5
  servingsNumber: 2
  servingsUnit: Servings
  ingredients:
    - { amount: "225 g (7 oz)", item: "boneless, skinless chicken thighs, cut into bite-size pieces" }
    - { amount: "1", item: "green onion, cut into 4 cm lengths, white and green parts kept apart" }
    - { amount: "1 cup", item: "Thai basil leaves, loosely packed (holy basil if you can find it)" }
    - { amount: "2 large", item: "garlic cloves, finely chopped" }
    - { amount: "1", item: "bird's eye chili, deseeded and finely chopped" }
    - { amount: "1 1/2 tbsp", item: "peanut or vegetable oil" }
    - { amount: "2 tsp", item: "oyster sauce" }
    - { amount: "1 tsp", item: "light soy sauce" }
    - { amount: "1 tsp", item: "dark soy sauce" }
    - { amount: "1 tsp", item: "sugar" }
    - { amount: "2 tbsp", item: "water" }
    - { amount: "To serve", item: "steamed jasmine rice" }
  steps:
    - "Stir the oyster sauce, both soy sauces, sugar and water together in a small bowl."
    - "Get a wok or large pan very hot, add the oil, then the garlic and chili. Give them about 10 seconds; the chili fumes are strong, so keep your face back."
    - "Add the chicken and the white part of the green onion and stir-fry about 2 minutes, until the chicken is cooked."
    - "Pour in the sauce and let it bubble for a minute, until the water cooks off and it coats the chicken."
    - "Toss in the green onion tops and basil, stir just until the basil wilts, and serve straight away over rice."
note: "Adapted from RecipeTin Eats' Thai chilli basil chicken (4.93 stars from 165 votes). A fried egg on top is the classic street-food way to eat it."
