---
title: "Pavlova"
slug: pavlova
date: 2026-01-01
category: Dessert
cuisine: "Australian"
description: "Crisp-shelled, marshmallow-centered meringue nests topped with whipped cream and fresh fruit."
image: ""
recipeContent:
  prepTimeMinutes: 30
  cookTimeMinutes: 105
  servingsNumber: 15
  servingsUnit: Pavlovas
  ingredients:
    - { amount: "6", item: "large egg whites, room temperature" }
    - { amount: "1 1/2 cups", item: "granulated sugar" }
    - { amount: "2 tsp", item: "cornstarch" }
    - { amount: "1/2 tbsp", item: "lemon juice" }
    - { amount: "1/2 tbsp", item: "vanilla extract" }
    - { amount: "1 1/2 cups", item: "heavy whipping cream, very cold" }
    - { amount: "2 tbsp", item: "granulated sugar, for the cream" }
    - { amount: "4-5 cups", item: "fresh fruit (berries, kiwi, sliced strawberries)" }
    - { amount: "15", item: "mint leaves, to garnish (optional)" }
  steps:
    - "Heat the oven to 225°F and line a large baking sheet with parchment."
    - "Beat the egg whites on high 1 minute until soft peaks form. With the mixer running, add the sugar gradually, then beat 10 minutes until stiff, smooth and glossy."
    - "Fold in the lemon juice, vanilla and cornstarch."
    - "Pipe or spoon into 3-3.5 inch nests on the parchment and make a dip in the center of each."
    - "Bake 1 hour 15 minutes, then turn the oven off and leave the pavlovas in the closed oven for 30 minutes."
    - "Cool completely on the counter."
    - "Whip the cold cream with 2 tbsp sugar until spreadable, about 2-2 1/2 minutes."
    - "Top each nest with cream and fruit, and add mint if you like."
note: "Adapted from Natasha's Kitchen's pavlova (4.95 stars from 446 votes). Top just before serving, because the cream softens the meringue."
