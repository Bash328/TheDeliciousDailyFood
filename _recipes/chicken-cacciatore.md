category: Dinner
cuisine: "Italian"
description: "Hunter-style braised chicken with mushrooms, peppers, red wine, tomato, rosemary and olives. Serve over mash or polenta."
image: ""
recipeContent:
  prepTimeMinutes: 15
  cookTimeMinutes: 55
  servingsNumber: 4
  servingsUnit: Servings
  ingredients:
    - { amount: "4 large", item: "bone-in, skin-on chicken thighs (about 1 kg / 2 lb)" }
    - { amount: "4", item: "chicken drumsticks" }
    - { amount: "3/4 tsp", item: "kosher salt, divided" }
    - { amount: "1/2 tsp", item: "black pepper, divided" }
    - { amount: "1 tbsp", item: "olive oil" }
    - { amount: "1", item: "onion, halved and finely sliced" }
    - { amount: "2 sprigs", item: "rosemary (or 1 tsp dried)" }
    - { amount: "2", item: "bay leaves" }
    - { amount: "1 tsp", item: "dried oregano" }
    - { amount: "3", item: "garlic cloves, finely minced" }
    - { amount: "3", item: "anchovy fillets (optional)" }
    - { amount: "250 g (8 oz)", item: "mushrooms, sliced" }
    - { amount: "2", item: "red bell peppers, sliced 8 mm thick" }
    - { amount: "1/3 cup", item: "tomato paste" }
    - { amount: "3/4 cup", item: "dry red wine" }
    - { amount: "2 cups", item: "low-sodium chicken broth" }
    - { amount: "400 g (14 oz)", item: "canned crushed tomatoes" }
    - { amount: "16", item: "pitted kalamata olives" }
    - { amount: "To serve", item: "mashed potato or polenta, and chopped parsley" }
  steps:
    - "Season the chicken with 1/2 tsp salt and 1/4 tsp pepper. Heat the oil in a large, deep, lidded pan over high heat and brown the thighs skin-side down, about 6 minutes, then 1 minute on the other side. Brown the drumsticks all over. Set aside."
    - "Pour off all but about 2 tbsp fat and lower the heat to medium. Cook the onion, rosemary leaves, bay leaves and oregano for 3 minutes."
    - "Clear a space and cook the garlic and anchovies, mashing the anchovies, until the garlic is lightly golden. Stir together."
    - "Turn the heat to high, add the mushrooms and peppers and cook about 5 minutes, until the mushroom liquid evaporates. Add the tomato paste and cook 2 minutes."
    - "Pour in the wine and boil until reduced by about three quarters. Add the broth, tomatoes and the rest of the salt and pepper and bring to a simmer."
    - "Nestle the chicken in skin-side up with any juices. Cover and simmer briskly over medium heat for 20 minutes, then uncover, add the olives and simmer 10 minutes more to thicken. Serve over mash or polenta with parsley."
note: "Adapted from RecipeTin Eats' chicken cacciatore (4.9 stars from 49 votes). The anchovies melt away and just add savoury depth."
