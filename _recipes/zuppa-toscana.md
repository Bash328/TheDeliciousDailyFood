recipeContent:
  prepTimeMinutes: 20
  cookTimeMinutes: 35
  servingsNumber: 4
  servingsUnit: Bowls
  ingredients:
    - { amount: "1 lb", item: "Italian sausage (mild or spicy), removed from casings" }
    - { amount: "1", item: "medium yellow onion, diced" }
    - { amount: "2", item: "medium carrots, diced" }
    - { amount: "3", item: "garlic cloves, minced" }
    - { amount: "3 tbsp", item: "all-purpose flour" }
    - { amount: "4 cups", item: "chicken broth" }
    - { amount: "1 lb", item: "Yukon Gold potatoes, diced into 1/2-inch pieces" }
    - { amount: "1/4 tsp", item: "salt" }
    - { amount: "1/8 tsp", item: "black pepper" }
    - { amount: "1/8 tsp", item: "crushed red pepper flakes (optional)" }
    - { amount: "2 cups", item: "baby spinach, stems removed, packed" }
    - { amount: "1/2 cup", item: "heavy cream" }
    - { amount: "3 tbsp", item: "grated Parmigiano Reggiano or Pecorino Romano, plus more for serving" }
  steps:
    - "Cook the sausage in a large pot over medium heat, breaking it up, 5-7 minutes. Move it with a slotted spoon to a colander, leaving about 1 tbsp of drippings in the pot."
    - "Cook the onion and carrots in the drippings 4-5 minutes (add a little oil if dry). Add the garlic 30 seconds, then sprinkle in the flour and stir for 1 minute."
    - "Gradually pour in the broth, scraping up the browned bits. Add the potatoes, salt, pepper and red pepper flakes, bring to a boil, then cover and simmer on low about 15 minutes until the potatoes are tender, stirring now and then."
    - "Blot the sausage on paper towels to remove excess grease."
    - "Add the spinach and sausage and simmer a few minutes until the spinach wilts. Stir in the cream and cheese and warm through."
    - "Adjust the seasoning and serve hot with more cheese."
note: "Adapted from Once Upon a Chef's zuppa toscana (4.99 stars from 73 votes). Kale works in place of spinach."
