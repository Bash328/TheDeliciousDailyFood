tag: "Classic"
description: "Tender cinnamon apples in a buttery, flaky double crust."
image: ""
recipeContent:
  prepTimeMinutes: 45
  cookTimeMinutes: 60
  servingsNumber: 8
  servingsUnit: Slices
  ingredients:
    - { amount: "2", item: "refrigerated pie crusts (9-inch)" }
    - { amount: "6 cups", item: "peeled, sliced tart apples (about 6 apples)" }
    - { amount: "3/4 cup", item: "granulated sugar" }
    - { amount: "2 tbsp", item: "all-purpose flour" }
    - { amount: "1 tbsp", item: "lemon juice" }
    - { amount: "1 tsp", item: "ground cinnamon" }
    - { amount: "1/4 tsp", item: "ground nutmeg" }
    - { amount: "1/4 tsp", item: "salt" }
    - { amount: "2 tbsp", item: "butter, cut into small pieces" }
    - { amount: "1", item: "egg, beaten" }
    - { amount: "1 tbsp", item: "coarse sugar" }
  steps:
    - "Heat the oven to 425°F. Fit one crust into a 9-inch pie plate."
    - "Toss the apples with the sugar, flour, lemon juice, cinnamon, nutmeg and salt. Mound into the crust and dot with the butter."
    - "Cover with the second crust, trim and crimp, and cut several vents in the top."
    - "Brush with the egg and sprinkle with coarse sugar."
    - "Bake 20 minutes, reduce the heat to 375°F, and bake 40 minutes more until the crust is deep golden and the filling bubbles."
    - "Cool at least 2 hours so the filling sets."
note: "Cover the crust edges with foil if they brown too quickly."
