recipeContent:
  prepTimeMinutes: 15
  cookTimeMinutes: 75
  servingsNumber: 6
  servingsUnit: Servings
  ingredients:
    - { amount: "2", item: "large boneless, skinless chicken breasts, cut into bite-sized pieces" }
    - { amount: "1 cup", item: "plain full-fat yogurt" }
    - { amount: "1 tsp", item: "turmeric" }
    - { amount: "2 tsp", item: "garam masala" }
    - { amount: "1 tbsp", item: "fresh lemon juice" }
    - { amount: "2 tsp", item: "freshly cracked black pepper" }
    - { amount: "1/4 tsp", item: "ground ginger" }
    - { amount: "4 tbsp", item: "ghee" }
    - { amount: "3/4 cup", item: "minced white onion" }
    - { amount: "1-2", item: "serrano chilies, minced" }
    - { amount: "3 tbsp", item: "minced fresh garlic (5-6 cloves)" }
    - { amount: "1 1/2 tbsp", item: "grated fresh ginger" }
    - { amount: "3 1/2 tsp", item: "garam masala, for the sauce" }
    - { amount: "1 tsp", item: "paprika" }
    - { amount: "1 can (15 oz)", item: "tomato sauce" }
    - { amount: "1", item: "green bell pepper, cut into strips" }
    - { amount: "1 tbsp", item: "dried fenugreek leaves (kasuri methi)" }
    - { amount: "To taste", item: "salt" }
    - { amount: "2 cups", item: "heavy cream, at room temperature" }
    - { amount: "To serve", item: "basmati rice, chopped cilantro and naan" }
  steps:
    - "Stir the yogurt, turmeric, garam masala, lemon juice, pepper and ground ginger together, add the chicken and coat well. Cover and refrigerate 1 to 8 hours."
    - "Melt the ghee in a large skillet over medium heat and cook the onion about 5 minutes until soft."
    - "Add the chilies, garlic and fresh ginger, turn the heat to medium-low and cook about 20 minutes, stirring now and then, until the mixture turns a deep toffee color. Add a few drops of water if it sticks."
    - "Stir in the garam masala and paprika for 2-3 minutes, then add the tomato sauce. Take off the heat and let cool slightly."
    - "Heat the broiler and broil the chicken on a rack-lined pan for 6-8 minutes, turning once, until it reaches 160°F inside. Set aside."
    - "Blend the cooled sauce until smooth and return it to the pan with the bell pepper, fenugreek and salt. Simmer on medium-low 30 minutes until thick and paste-like."
    - "Take off the heat, stir in the cream, return to the heat, taste and adjust."
    - "Add the chicken and warm through. Serve over rice with cilantro and naan."
note: "Adapted from 40 Aprons' restaurant-style chicken tikka masala (4.97 stars from 151 votes). Cooking the onion mix to a deep toffee color is the step that matters most."
