    - { amount: "3/4 cup", item: "whole milk" }
    - { amount: "1/2 cup", item: "dark brown sugar" }
    - { amount: "2", item: "large eggs" }
    - { amount: "3 tbsp", item: "apricot jam, strained" }
    - { amount: "2 tbsp", item: "butter, melted" }
    - { amount: "1 tsp", item: "apple cider vinegar" }
    - { amount: "1 1/2 cups", item: "all-purpose flour" }
    - { amount: "2 tsp", item: "baking powder" }
    - { amount: "1 tsp", item: "baking soda" }
    - { amount: "Pinch", item: "salt" }
    - { amount: "1/2 cup", item: "heavy cream" }
    - { amount: "1/2 cup", item: "whole milk, for the sauce" }
    - { amount: "1/2 cup", item: "butter, for the sauce" }
    - { amount: "1/2 cup", item: "sugar" }
    - { amount: "1/4 tsp", item: "salt, for the sauce" }
  steps:
    - "Heat the oven to 350°F and butter an 8-inch square baking dish."
    - "Whisk the milk, brown sugar, eggs, jam, melted butter and vinegar until smooth."
    - "Whisk the flour, baking powder, baking soda and salt in a separate bowl, then mix into the wet ingredients until combined."
    - "Pour into the dish and bake 30-40 minutes until a knife in the center comes out clean."
    - "Just before it's done, heat the cream, milk, butter, sugar and salt in a pan until the butter has melted and the sugar has dissolved."
    - "Prick the hot pudding all over with a skewer and pour the warm sauce over it. Let it rest at least 30 minutes."
    - "Serve warm with vanilla ice cream or custard."
note: "Adapted from Bigger Bolder Baking's South African malva pudding (4.4 stars from 154 votes). Keeps in the fridge up to 3 days."
