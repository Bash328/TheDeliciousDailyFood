cuisine: "American"
description: "Crisp-coated chicken pieces baked in a tangy ketchup and cider vinegar glaze until sticky. Serve with rice and broccoli."
image: ""
recipeContent:
  prepTimeMinutes: 20
  cookTimeMinutes: 70
  servingsNumber: 6
  servingsUnit: Servings
  ingredients:
    - { amount: "2 lb", item: "boneless, skinless chicken breasts (about 4), cut into 2.5 cm pieces" }
    - { amount: "To taste", item: "salt and pepper" }
    - { amount: "1 cup", item: "cornstarch" }
    - { amount: "3 large", item: "eggs, lightly beaten" }
    - { amount: "1/4 cup", item: "vegetable oil, plus more as needed" }
    - { amount: "1/2 cup", item: "apple cider vinegar" }
    - { amount: "4 tbsp", item: "ketchup" }
    - { amount: "1 tbsp", item: "soy sauce" }
    - { amount: "3/4 cup", item: "granulated sugar" }
    - { amount: "1 tsp", item: "garlic salt" }
    - { amount: "To serve", item: "steamed rice and broccoli" }
  steps:
    - "Heat the oven to 160°C / 325°F. Season the chicken with salt and pepper and toss it in the cornstarch to coat."
    - "Heat the oil in a large, deep pot until very hot. Dip the chicken in the beaten eggs, then fry in batches about 30 seconds a side, just until golden; it finishes in the oven. Move to a 9x13-inch baking dish. Add more oil between batches as needed, letting it heat up first."
    - "Stir the vinegar, ketchup, soy sauce, sugar and garlic salt together and pour over the chicken, tossing to coat."
    - "Bake uncovered for 1 hour, turning the chicken twice so it stays coated. Serve hot over rice with broccoli."
note: "Adapted from Natasha's Kitchen's sweet and sour chicken (4.89 stars from 151 votes)."
