---
title: "Banana Muffins"
date: 2026-11-25
category: Breakfast
cuisine: "American"
description: "Quick, soft, high-domed banana muffins with cinnamon and brown sugar. One bowl of wet ingredients, one of dry."
image: ""
recipeContent:
  prepTimeMinutes: 10
  cookTimeMinutes: 20
  servingsNumber: 12
  servingsUnit: Muffins
  ingredients:
    - { amount: "1 1/2 cups (188 g)", item: "all-purpose flour" }
    - { amount: "1 tsp", item: "baking powder" }
    - { amount: "1 tsp", item: "baking soda" }
    - { amount: "1/2 tsp", item: "salt" }
    - { amount: "1 tsp", item: "ground cinnamon" }
    - { amount: "1/4 tsp", item: "ground nutmeg" }
    - { amount: "1 1/2 cups (345 g)", item: "mashed ripe bananas (3-4)" }
    - { amount: "6 tbsp (85 g)", item: "unsalted butter, melted" }
    - { amount: "2/3 cup (135 g)", item: "packed brown sugar" }
    - { amount: "1 large", item: "egg, at room temperature" }
    - { amount: "1 tsp", item: "vanilla extract" }
    - { amount: "2 tbsp", item: "milk" }
    - { amount: "1 cup", item: "chopped walnuts, pecans or chocolate chips (optional)" }
  steps:
    - "Heat the oven to 220°C / 425°F and grease or line a 12-cup muffin pan."
    - "Whisk the flour, baking powder, baking soda, salt, cinnamon and nutmeg together."
    - "Mash the bananas in a large bowl, then whisk in the melted butter, brown sugar, egg, vanilla and milk."
    - "Add the dry ingredients and stir just until combined. Fold in any nuts or chips. The batter is thick."
    - "Fill the cups right to the top. Bake 5 minutes, then lower the oven to 180°C / 350°F without opening the door and bake 16-18 minutes more, until a toothpick comes out clean."
    - "Cool 5 minutes in the pan, then on a rack."
note: "Adapted from Sally's Baking Addiction's banana muffins (4.9 stars from 2,253 votes). Makes 10-12."
