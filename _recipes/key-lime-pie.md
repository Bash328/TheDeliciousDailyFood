category: Dessert
tag: "American"
description: "A tangy, creamy lime pie in a graham cracker crust, topped with whipped cream."
image: ""
recipeContent:
  prepTimeMinutes: 20
  cookTimeMinutes: 25
  servingsNumber: 8
  servingsUnit: Slices
  ingredients:
    - { amount: "1 1/2 cups", item: "finely crushed graham cracker crumbs (about 12 crackers)" }
    - { amount: "1/3 cup", item: "packed light brown sugar" }
    - { amount: "4 tbsp", item: "unsalted butter, melted" }
    - { amount: "2 cans (14 oz each)", item: "sweetened condensed milk" }
    - { amount: "1 cup", item: "plain Greek yogurt" }
    - { amount: "1 tbsp", item: "grated lime zest" }
    - { amount: "3/4 cup", item: "fresh lime juice" }
    - { amount: "1 cup", item: "cold heavy cream" }
    - { amount: "2 tbsp", item: "confectioners' sugar" }
    - { amount: "1 tsp", item: "grated lime zest, for the topping" }
    - { amount: "8-10", item: "thin lime slices, to decorate" }
  steps:
    - "Heat the oven to 375°F with a rack in the middle."
    - "Mix the crumbs, brown sugar and melted butter with a fork, then your hands. Press firmly into the bottom and up the sides of a 9-inch deep pie dish."
    - "Bake 10 minutes until just slightly browned and cool on a rack."
    - "Lower the oven to 350°F. Whisk the condensed milk, yogurt, lime zest and lime juice and pour into the warm crust."
    - "Bake 15 minutes until almost set (it should still wobble). Cool 30 minutes at room temperature, then chill about 3 hours."
    - "Whip the cream to soft peaks, add the confectioners' sugar and beat to medium peaks."
    - "Top the pie with the whipped cream, lime zest and lime slices."
    - "Slice with a clean knife and serve cold."
note: "Adapted from Once Upon a Chef's egg-free key lime pie (4.83 stars from 980 votes). Regular grocery-store limes work well."
