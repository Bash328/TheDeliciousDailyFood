  ingredients:
    - { amount: "3", item: "egg yolks" }
    - { amount: "1 tbsp", item: "lemon juice" }
    - { amount: "1/2 cup", item: "butter, melted" }
    - { amount: "Pinch", item: "cayenne and salt" }
    - { amount: "4", item: "English muffins, split and toasted" }
    - { amount: "8 slices", item: "Canadian bacon" }
    - { amount: "8", item: "eggs" }
    - { amount: "1 tbsp", item: "white vinegar" }
  steps:
    - "For the hollandaise, whisk the yolks and lemon juice in a bowl set over a pan of barely simmering water until thickened. Slowly drizzle in the warm butter, whisking constantly. Season with cayenne and salt and keep warm."
    - "Warm the Canadian bacon in a skillet."
    - "Bring a wide pan of water to a gentle simmer with the vinegar. Crack each egg into a small cup and slide it into the water. Poach 3-4 minutes and lift out with a slotted spoon."
    - "Stack bacon on each muffin half, top with a poached egg and spoon over the hollandaise."
note: "If the hollandaise gets too thick, whisk in a teaspoon of warm water."
