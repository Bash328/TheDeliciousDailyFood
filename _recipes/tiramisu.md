---
title: "Tiramisu"
slug: tiramisu
date: 2026-01-01
category: Dessert
cuisine: "Italian"
description: "A no-bake layered dessert of espresso-dipped ladyfingers and a light mascarpone cream."
image: ""
recipeContent:
  prepTimeMinutes: 45
  cookTimeMinutes: 0
  servingsNumber: 12
  servingsUnit: Slices
  ingredients:
    - { amount: "1 cup", item: "very strong espresso, warm or room temperature" }
    - { amount: "5 tbsp", item: "Grand Marnier (optional)" }
    - { amount: "40-45", item: "ladyfingers" }
    - { amount: "16 oz", item: "mascarpone, cold" }
    - { amount: "2 tbsp", item: "dark rum" }
    - { amount: "4", item: "large pasteurized eggs, separated" }
    - { amount: "1/2 cup", item: "granulated sugar, divided" }
    - { amount: "2 cups", item: "heavy cream" }
    - { amount: "1/2 tsp", item: "vanilla extract" }
    - { amount: "1/8 tsp", item: "salt" }
    - { amount: "To dust", item: "unsweetened cocoa powder" }
  steps:
    - "You'll need a 9x13-inch dish with at least a 12-cup capacity. Whisk the espresso and Grand Marnier in a shallow bowl."
    - "Dip each ladyfinger quickly on both sides (a quick dip, so they don't go soggy) and make one solid layer in the dish, cutting some to fill gaps. Save the remaining espresso and ladyfingers."
    - "Beat the mascarpone and rum together briefly, just to combine."
    - "Set a heatproof bowl over simmering water (not touching it) and whisk the egg yolks with 1/4 cup sugar about 5 minutes until light and foamy. Pour into the mascarpone and beat until combined."
    - "Whip the cream with the vanilla to medium peaks and fold it into the mascarpone mixture."
    - "Beat the egg whites with the salt until foamy, slowly add the remaining 1/4 cup sugar and beat to stiff peaks. Fold into the cream."
    - "Spread half the cream over the ladyfingers. Dip the remaining ladyfingers, make a second layer and cover with the rest of the cream."
    - "Refrigerate uncovered 2-3 hours, then dust a layer of cocoa over the top. Cover and chill at least 8-9 more hours, up to a day."
    - "Slice with a sharp knife, wiping it clean between cuts."
note: "Adapted from Sally's Baking Addiction's tiramisu (4.8 stars from 191 votes). It uses raw egg whites, so use pasteurized eggs. Keeps up to 3 days in the fridge."
