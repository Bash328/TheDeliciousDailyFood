category: Soup
cuisine: "Eastern European"
description: "A hearty tomato and beef broth loaded with cabbage, carrot and ground beef, finished with fresh dill."
image: ""
recipeContent:
  prepTimeMinutes: 15
  cookTimeMinutes: 35
  servingsNumber: 6
  servingsUnit: Bowls
  ingredients:
    - { amount: "1 lb", item: "ground beef (80-85% lean)" }
    - { amount: "2 tbsp", item: "oil, divided" }
    - { amount: "1 medium", item: "onion, finely chopped" }
    - { amount: "3", item: "garlic cloves, minced" }
    - { amount: "4 cups", item: "green cabbage, chopped (about 1/2 large head)" }
    - { amount: "1 large", item: "carrot, sliced" }
    - { amount: "1", item: "celery rib, thinly sliced" }
    - { amount: "28 oz", item: "canned diced tomatoes, with juice" }
    - { amount: "15 oz", item: "tomato sauce" }
    - { amount: "4 cups", item: "beef broth" }
    - { amount: "2 tbsp", item: "brown sugar" }
    - { amount: "1 1/2 tsp", item: "salt, divided, to taste" }
    - { amount: "3/4 tsp", item: "black pepper, divided" }
    - { amount: "2", item: "bay leaves" }
    - { amount: "2 tbsp", item: "fresh dill, parsley or cilantro, chopped" }
    - { amount: "To serve", item: "sour cream" }
  steps:
    - "Heat 1 tbsp oil in a Dutch oven over medium-high heat and brown the beef, breaking it up, 4-5 minutes. Season with 1/2 tsp salt and 1/4 tsp pepper."
    - "Add the remaining oil and the onion and cook 2-3 minutes until tender, then the garlic for 30 seconds."
    - "Add the cabbage, carrot, celery, tomatoes, tomato sauce, broth, brown sugar, 1 tsp salt, 1/2 tsp pepper and the bay leaves. Bring to a boil, then cover and simmer 30 minutes."
    - "Remove the bay leaves, stir in the herbs and adjust the seasoning. Serve with a spoonful of sour cream."
note: "Adapted from Natasha's Kitchen's cabbage soup (4.99 stars from 201 votes). Freezes well."
