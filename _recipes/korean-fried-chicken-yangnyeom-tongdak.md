recipeContent:
  prepTimeMinutes: 10
  cookTimeMinutes: 40
  servingsNumber: 4
  servingsUnit: Servings
  ingredients:
    - { amount: "2 lbs", item: "chicken wings" }
    - { amount: "1/2 tsp", item: "kosher salt" }
    - { amount: "1/2 tsp", item: "ground black pepper" }
    - { amount: "1/2 cup", item: "potato starch" }
    - { amount: "1/4 cup", item: "all-purpose flour" }
    - { amount: "1/2 tsp", item: "baking soda" }
    - { amount: "2", item: "large eggs" }
    - { amount: "For frying", item: "corn or vegetable oil, about 2 inches deep" }
    - { amount: "1 tbsp", item: "toasted sesame seeds" }
    - { amount: "2 tsp", item: "vegetable oil, for the sauce" }
    - { amount: "3", item: "garlic cloves, minced" }
    - { amount: "1/3 cup", item: "ketchup" }
    - { amount: "1/3 cup", item: "rice syrup" }
    - { amount: "1/4 cup", item: "gochujang (Korean hot pepper paste)" }
    - { amount: "2 tsp", item: "white vinegar" }
  steps:
    - "Heat 2 inches of oil in a large heavy pan over medium-high heat to 330-350°F, about 10-12 minutes. Work in batches if your pan is small."
    - "Meanwhile, mix the chicken with the salt, pepper, potato starch, flour, baking soda and eggs by hand until evenly coated."
    - "Add the chicken to the oil piece by piece and fry about 12 minutes, turning, until golden and crunchy. Drain on a wire rack."
    - "For the sauce, cook the garlic in 2 tsp oil for about 30 seconds. Add the ketchup, rice syrup, gochujang and vinegar, stir, then reduce the heat to low and stir until bubbling. Remove from the heat."
    - "Reheat the oil to 330-350°F (about 2 minutes) and fry the chicken a second time, about 12 minutes, until very crunchy."
    - "Reheat the sauce until bubbling, add the hot chicken and toss well. Sprinkle with sesame seeds."
    - "Serve with pickled radish if you have it."
note: "Adapted from Maangchi's yangnyeom-tongdak. The page's data didn't include a star average I could read. Frying twice is what makes the coating stay crisp under the sauce."
