---
title: "Chicken Marsala"
date: 2026-11-25
category: Dinner
cuisine: "Italian"
description: "Thin golden chicken cutlets in a creamy mushroom and Marsala wine sauce, done in about 30 minutes."
image: ""
recipeContent:
  prepTimeMinutes: 10
  cookTimeMinutes: 20
  servingsNumber: 4
  servingsUnit: Servings
  ingredients:
    - { amount: "1 1/4 lb", item: "chicken breasts (2 large), or chicken tenders" }
    - { amount: "1/2 tsp", item: "salt, plus more to taste" }
    - { amount: "1/4 tsp", item: "black pepper" }
    - { amount: "1/4 cup", item: "all-purpose flour, for dredging" }
    - { amount: "2 tbsp", item: "olive oil" }
    - { amount: "1 tbsp", item: "unsalted butter" }
    - { amount: "8 oz", item: "brown button mushrooms, halved or thickly sliced" }
    - { amount: "1/2 tsp", item: "onion powder" }
    - { amount: "2", item: "garlic cloves, minced" }
    - { amount: "3/4 cup", item: "dry Marsala wine" }
    - { amount: "3/4 cup", item: "reduced-sodium chicken stock" }
    - { amount: "1/2 cup", item: "heavy cream" }
    - { amount: "2 tbsp", item: "parsley, finely chopped" }
  steps:
    - "Slice each breast in half horizontally to make 4 cutlets, then pound them between plastic wrap to about 1 cm (1/3 inch) thick. Season with the salt and pepper and dredge in flour, shaking off the extra."
    - "Heat the oil and butter in a large heavy pan over medium heat. Cook the chicken 3-4 minutes a side, until golden and cooked through (74°C / 165°F). Set aside under foil."
    - "Add the mushrooms (and a little more oil if the pan is dry) and cook until their liquid is gone and they're browned, about 5 minutes. Stir in the onion powder and garlic for 30 seconds."
    - "Pour in the Marsala, scraping up the browned bits, and boil until mostly reduced, 4-5 minutes. Add the stock, then stream in the cream and simmer 4-5 minutes until slightly thickened. Season to taste."
    - "Return the chicken, scatter with parsley, spoon the sauce over and warm through for 2 minutes. The sauce thickens more as it stands."
note: "Adapted from Natasha's Kitchen's chicken Marsala (4.97 stars from 556 votes). Use dry Marsala, not sweet."
