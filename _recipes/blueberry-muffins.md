title: "Lemon Blueberry Muffins"
slug: blueberry-muffins
date: 2026-06-22
category: Breakfast
tag: "Baking"
description: "The trick to a tall bakery-style dome is a hot oven for the first few minutes. Everything else is just good muffin math."
image: ""
prepTimeMinutes: 15
cookTimeMinutes: 25
servingsNumber: 12
servingsUnit: Muffins
ingredients:
  - { amount: "2 cups", item: "all-purpose flour" }
  - { amount: "3/4 cup", item: "granulated sugar, plus extra for topping" }
  - { amount: "2 tsp", item: "baking powder" }
  - { amount: "1/2 tsp", item: "salt" }
  - { amount: "2", item: "large eggs" }
  - { amount: "1/2 cup", item: "vegetable oil" }
  - { amount: "1/2 cup", item: "sour cream" }
  - { amount: "1/3 cup", item: "whole milk" }
  - { amount: "1", item: "lemon, zested and juiced" }
  - { amount: "1 1/2 cups", item: "blueberries, fresh or frozen" }
steps:
  - "Preheat oven to 425°F (220°C). Line a muffin tin with liners."
  - "Whisk flour, sugar, baking powder, and salt in a large bowl."
  - "In a separate bowl, whisk eggs, oil, sour cream, milk, lemon zest, and lemon juice until smooth."
  - "Pour the wet ingredients into the dry and fold just until combined. Gently fold in the blueberries."
  - "Divide batter evenly among the liners, filling almost to the top. Sprinkle with sugar."
  - "Bake at 425°F for 5 minutes, then reduce oven to 350°F (175°C) without opening the door, and bake 18-20 minutes more until a toothpick comes out clean."
note: "Toss frozen blueberries in a spoonful of flour before folding in — keeps them from sinking."
