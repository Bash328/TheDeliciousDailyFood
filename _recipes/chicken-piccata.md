cuisine: "Italian"
description: "Crisp breaded chicken cutlets with a bright lemon, caper and butter pan sauce."
image: ""
recipeContent:
  prepTimeMinutes: 15
  cookTimeMinutes: 15
  servingsNumber: 4
  servingsUnit: Servings
  ingredients:
    - { amount: "1 1/2 lbs", item: "boneless, skinless chicken breasts" }
    - { amount: "3 tbsp", item: "all-purpose flour" }
    - { amount: "To taste", item: "salt and freshly ground black pepper" }
    - { amount: "2", item: "eggs" }
    - { amount: "1 cup", item: "seasoned Italian bread crumbs" }
    - { amount: "1/4 cup", item: "extra-virgin olive oil" }
    - { amount: "1 cup", item: "chicken stock" }
    - { amount: "2 tbsp", item: "fresh lemon juice (from 1 lemon)" }
    - { amount: "3 tbsp", item: "brined capers, drained and rinsed" }
    - { amount: "3 tbsp", item: "unsalted butter" }
    - { amount: "1/4 cup", item: "chopped fresh Italian parsley" }
  steps:
    - "Heat the oven to 350°F and line a baking sheet with foil."
    - "Slice each chicken breast in half horizontally, then pound each piece to an even 1/4-inch thickness."
    - "Shake the chicken in a bag with the flour, 3/4 tsp salt and 1/4 tsp pepper. Beat the eggs in one shallow bowl and mix the bread crumbs with 1/4 tsp salt in another. Dip each cutlet in egg, then bread crumbs, turning to coat."
    - "Heat the oil in a large sauté pan over medium-high heat. Cook the chicken until golden, 2-3 minutes on the first side and about 2 minutes on the second."
    - "Move it to the baking sheet and into the oven while you make the sauce. It should be nearly cooked through, so don't leave it more than 5 minutes."
    - "Drain off the excess oil from the pan, add the stock, lemon juice and capers and boil gently about 2 minutes, scraping up the browned bits."
    - "Off the heat, swirl in the butter and parsley and adjust the seasoning. Plate the chicken and spoon the sauce over."
note: "Adapted from Once Upon a Chef's chicken piccata (4.91 stars from 179 votes)."
