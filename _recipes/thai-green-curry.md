  prepTimeMinutes: 15

  servingsNumber: 4
  servingsUnit: Servings
  ingredients:
    - { amount: "2 tbsp", item: "vegetable oil" }
    - { amount: "4-6 tbsp", item: "Thai green curry paste (Maesri is best)" }
    - { amount: "1 cup", item: "low-sodium chicken or vegetable broth" }
    - { amount: "14 oz (400 g)", item: "full-fat coconut milk" }
    - { amount: "1 tsp", item: "fish sauce, plus more to taste" }
    - { amount: "1 tsp", item: "white sugar, plus more to taste" }
    - { amount: "6", item: "kaffir lime leaves, torn in half" }
    - { amount: "12 oz", item: "boneless, skinless chicken thighs, sliced" }
    - { amount: "2", item: "small Japanese eggplants, sliced 1 cm thick" }
    - { amount: "1 1/2 cups", item: "snow peas, trimmed" }
    - { amount: "16", item: "Thai basil leaves" }
    - { amount: "Juice of 1/2", item: "lime" }
    - { amount: "To serve", item: "jasmine rice, fried shallots, Thai basil and chilies" }
  steps:
    - "Heat the oil in a heavy skillet or pot over medium-high heat. Fry the curry paste for 2-3 minutes until it mostly dries out."
    - "Add the broth and coconut milk and stir to dissolve the paste. Add the fish sauce, sugar and lime leaves and bring to a simmer."
    - "Add the chicken, lower the heat to medium so it bubbles gently, and cook 7 minutes."
    - "Add the eggplant and cook 5 minutes until soft. Taste and add fish sauce for salt or sugar for sweetness."
    - "Add the snow peas and cook 2 minutes, then stir in the basil and lime juice. Don't keep simmering, or the sauce darkens."
    - "Serve over jasmine rice, garnished with fried shallots, basil and sliced chilies."
note: "Adapted from RecipeTin Eats' Thai green curry (4.96 stars from 281 votes). The sauce is meant to be on the thin side."
