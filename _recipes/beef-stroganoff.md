  ingredients:
    - { amount: "1 lb", item: "top sirloin steak, thinly sliced into strips" }
    - { amount: "2 tbsp", item: "olive oil" }
    - { amount: "2 tbsp", item: "unsalted butter" }
    - { amount: "1/2", item: "medium onion, finely chopped" }
    - { amount: "1/2 lb", item: "brown mushrooms, thickly sliced" }
    - { amount: "1", item: "garlic clove, minced" }
    - { amount: "1 tbsp", item: "all-purpose flour" }
    - { amount: "1 cup", item: "beef broth" }
    - { amount: "3/4 cup", item: "heavy whipping cream" }
    - { amount: "1/4 cup", item: "sour cream" }
    - { amount: "1 tbsp", item: "Worcestershire sauce" }
    - { amount: "1/2 tsp", item: "Dijon mustard" }
    - { amount: "1/2 tsp", item: "salt" }
    - { amount: "1/4 tsp", item: "black pepper" }
    - { amount: "8-12 oz", item: "egg noodles, to serve (optional)" }
    - { amount: "To serve", item: "chopped green onion or parsley" }
  steps:
    - "Heat the oil in a large deep pan over medium-high heat until very hot. Sear the beef in two batches, a single layer, about 1 minute per side, until just browned. Set aside covered."
    - "Lower the heat to medium. Melt the butter and cook the onion and mushrooms 6-8 minutes until the liquid has evaporated and they're lightly browned."
    - "Add the garlic for 1 minute, then stir in the flour for another minute."
    - "Pour in the broth, scraping up the browned bits, add the cream and simmer 1-2 minutes until slightly thickened."
    - "Stir a few spoonfuls of the hot sauce into the sour cream to temper it, then stir it back into the pan."
    - "Add the Worcestershire, mustard, salt and pepper. Return the beef and its juices and heat just until it simmers."
    - "Serve over egg noodles with green onion or parsley."
note: "Adapted from Natasha's Kitchen's beef stroganoff (4.96 stars from 2,051 votes). Tempering the sour cream keeps it from curdling."
