tag: "Classic"
description: "Tall, tender pancakes with golden edges and a slight tang."
image: ""
recipeContent:
  prepTimeMinutes: 10
  cookTimeMinutes: 15
  servingsNumber: 4
  servingsUnit: Pancakes
  ingredients:
    - { amount: "2 cups", item: "all-purpose flour" }
    - { amount: "2 tbsp", item: "granulated sugar" }
    - { amount: "2 tsp", item: "baking powder" }
    - { amount: "1/2 tsp", item: "baking soda" }
    - { amount: "1/2 tsp", item: "salt" }
    - { amount: "2 cups", item: "buttermilk" }
    - { amount: "2", item: "large eggs" }
    - { amount: "3 tbsp", item: "butter, melted" }
    - { amount: "1 tsp", item: "vanilla extract" }
    - { amount: "To serve", item: "butter and maple syrup" }
  steps:
    - "Whisk the flour, sugar, baking powder, baking soda and salt in a large bowl."
    - "Whisk the buttermilk, eggs, melted butter and vanilla in another bowl."
    - "Pour the wet ingredients into the dry and stir until just combined. A few lumps are fine. Rest 5 minutes."
    - "Heat a lightly greased griddle or skillet over medium heat. Pour 1/4 cup batter per pancake."
    - "Cook until bubbles form and pop on the surface, 2-3 minutes. Flip and cook 1-2 minutes more until golden."
    - "Serve warm with butter and maple syrup."
note: "Overmixing is the enemy of fluffy pancakes. Stop as soon as the flour disappears."
