description: "A tender, juicy meatloaf with a sweet tangy ketchup glaze."
image: ""
recipeContent:
  prepTimeMinutes: 15
  cookTimeMinutes: 60
  servingsNumber: 6
  servingsUnit: Servings
  ingredients:
    - { amount: "2 lbs", item: "ground beef" }
    - { amount: "1/2 cup", item: "breadcrumbs" }
    - { amount: "1/2 cup", item: "whole milk" }
    - { amount: "2", item: "eggs" }
    - { amount: "1", item: "small onion, finely diced" }
    - { amount: "2", item: "garlic cloves, minced" }
    - { amount: "2 tbsp", item: "Worcestershire sauce" }
    - { amount: "1 tsp", item: "salt" }
    - { amount: "1/2 tsp", item: "black pepper" }
    - { amount: "1/2 cup", item: "ketchup" }
    - { amount: "2 tbsp", item: "brown sugar" }
    - { amount: "1 tbsp", item: "apple cider vinegar" }
  steps:
    - "Heat the oven to 350°F. Stir the breadcrumbs and milk together and let sit 5 minutes."
    - "Mix the beef, soaked breadcrumbs, eggs, onion, garlic, Worcestershire, salt and pepper gently, just until combined."
    - "Shape into a loaf on a lined baking sheet or in a loaf pan."
    - "Whisk the ketchup, brown sugar and vinegar. Spread half over the loaf."
    - "Bake 45 minutes, spread the remaining glaze on top, and bake 15 minutes more until it reaches 160°F inside."
    - "Rest 10 minutes before slicing."
note: "Don't overmix. Handling the meat too much makes the loaf dense."
