---
title: "Snickerdoodles"
slug: snickerdoodles
date: 2026-01-01
category: Dessert
tag: "Classic"
description: "Soft, tangy cookies rolled in cinnamon sugar."
image: ""
recipeContent:
  prepTimeMinutes: 15
  cookTimeMinutes: 10
  servingsNumber: 24
  servingsUnit: Cookies
  ingredients:
    - { amount: "1 cup", item: "butter, softened" }
    - { amount: "1 1/2 cups", item: "granulated sugar" }
    - { amount: "2", item: "large eggs" }
    - { amount: "2 tsp", item: "vanilla extract" }
    - { amount: "2 3/4 cups", item: "all-purpose flour" }
    - { amount: "2 tsp", item: "cream of tartar" }
    - { amount: "1 tsp", item: "baking soda" }
    - { amount: "1/2 tsp", item: "salt" }
    - { amount: "2 tbsp", item: "granulated sugar, for rolling" }
    - { amount: "2 tsp", item: "ground cinnamon" }
  steps:
    - "Heat the oven to 375°F. Beat the butter and 1 1/2 cups sugar until fluffy. Beat in the eggs and vanilla."
    - "Whisk the flour, cream of tartar, baking soda and salt, then stir into the butter mixture."
    - "Mix the 2 tbsp sugar and cinnamon in a small bowl."
    - "Roll the dough into 1 1/2-inch balls, coat in the cinnamon sugar and place on baking sheets."
    - "Bake 8-10 minutes until the edges are set and the centers are still soft."
note: "Cream of tartar is what gives snickerdoodles their signature tang."
