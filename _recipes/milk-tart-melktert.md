title: "Milk Tart (Melktert)"
slug: milk-tart-melktert
date: 2026-01-01
category: Dessert
tag: "South African"
description: "A sweet shortcrust shell filled with silky, vanilla-scented milk custard and dusted with cinnamon."
image: ""
recipeContent:
  prepTimeMinutes: 45
  cookTimeMinutes: 30
  servingsNumber: 8
  servingsUnit: Slices
  ingredients:
    - { amount: "12 tbsp", item: "unsalted butter, softened" }
    - { amount: "1/2 cup", item: "granulated sugar" }
    - { amount: "1", item: "large egg" }
    - { amount: "1/4 tsp", item: "almond extract" }
    - { amount: "2 cups", item: "all-purpose flour" }
    - { amount: "Pinch", item: "salt" }
    - { amount: "1/2 cup", item: "granulated sugar, for the filling" }
    - { amount: "3 tbsp", item: "all-purpose flour" }
    - { amount: "3 tbsp", item: "cornstarch" }
    - { amount: "Pinch", item: "salt" }
    - { amount: "2", item: "large eggs" }
    - { amount: "1 tsp", item: "vanilla extract" }
    - { amount: "4 cups", item: "whole milk" }
    - { amount: "1 tbsp", item: "unsalted butter" }
    - { amount: "1 tbsp", item: "ground cinnamon" }
  steps:
    - "Heat the oven to 350°F and grease a 9.5-inch pie dish."
    - "Cream the butter and sugar until pale, then beat in the egg and almond extract. Stir in the flour and salt and knead briefly into a soft dough. Chill 10 minutes."
    - "Roll or press the dough into the dish. Line with parchment and pie weights and bake blind 15 minutes until golden, then remove the weights and bake a few minutes more if the base isn't done. Let it cool completely."
    - "Whisk the sugar, flour, cornstarch, salt, eggs and vanilla in a heatproof bowl."
    - "Heat the milk and butter in a saucepan until the butter melts, without boiling. Whisk about a quarter of the milk into the egg mixture, then pour it all back into the pan."
    - "Stir constantly over medium heat until very thick and it falls from the spoon in ribbons, without boiling."
    - "Pour into the crust, cool, then refrigerate 2-3 hours. Dust with cinnamon before serving."
note: "Adapted from Feast and West's melktert (4.47 stars from 95 votes). Keeps 2-3 days in the fridge."
