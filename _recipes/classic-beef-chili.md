description: "A big pot of beef and beans with a deep, smoky chili-powder base that tastes better the next day."
image: ""
recipeContent:
  prepTimeMinutes: 15
  cookTimeMinutes: 75
  servingsNumber: 8
  servingsUnit: Servings
  ingredients:
    - { amount: "2 tbsp", item: "olive oil" }
    - { amount: "2 lbs", item: "ground beef" }
    - { amount: "1", item: "large yellow onion, diced" }
    - { amount: "1", item: "green bell pepper, diced" }
    - { amount: "4", item: "garlic cloves, minced" }
    - { amount: "3 tbsp", item: "chili powder" }
    - { amount: "2 tsp", item: "ground cumin" }
    - { amount: "1 tsp", item: "smoked paprika" }
    - { amount: "1 tsp", item: "dried oregano" }
    - { amount: "1 can (28 oz)", item: "crushed tomatoes" }
    - { amount: "1 cup", item: "beef broth" }
    - { amount: "1 can (15 oz)", item: "kidney beans, drained" }
    - { amount: "1 can (15 oz)", item: "pinto beans, drained" }
    - { amount: "1 tsp", item: "salt, plus more to taste" }
  steps:
    - "Heat the oil in a large pot over medium-high heat. Brown the beef, breaking it up, 8 minutes. Drain off excess fat."
    - "Add the onion and pepper and cook 5 minutes until soft. Stir in the garlic and cook 30 seconds."
    - "Add the chili powder, cumin, paprika, oregano and salt and stir for 1 minute to toast the spices."
    - "Pour in the tomatoes and broth and bring to a simmer. Cook uncovered over low heat for 45 minutes, stirring now and then."
    - "Add both beans and simmer another 15 minutes. Taste and adjust the salt."
    - "Serve topped with shredded cheddar, sour cream and sliced scallions."
note: "Chili thickens as it sits. Loosen leftovers with a splash of broth when reheating."
