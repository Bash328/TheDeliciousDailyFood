title: "Southern Sweet Potato Pie"
slug: southern-sweet-potato-pie
date: 2026-01-01
category: Dessert
tag: "Classic"
description: "A silky, spiced sweet potato custard in a flaky crust."
image: ""
recipeContent:
  prepTimeMinutes: 30
  cookTimeMinutes: 60
  servingsNumber: 8
  servingsUnit: Slices
  ingredients:
    - { amount: "2 lbs", item: "sweet potatoes" }
    - { amount: "1", item: "refrigerated pie crust (9-inch)" }
    - { amount: "1/4 cup", item: "butter, softened" }
    - { amount: "2/3 cup", item: "packed brown sugar" }
    - { amount: "2", item: "large eggs" }
    - { amount: "1 cup", item: "evaporated milk" }
    - { amount: "1 tsp", item: "vanilla extract" }
    - { amount: "1 tsp", item: "ground cinnamon" }
    - { amount: "1/2 tsp", item: "ground nutmeg" }
    - { amount: "1/4 tsp", item: "salt" }
  steps:
    - "Roast the sweet potatoes at 400°F for 45-60 minutes until very soft. Peel and mash until smooth, measuring 2 cups."
    - "Reduce the oven to 350°F. Fit the crust into a pie plate."
    - "Beat the butter and sugar into the sweet potato, then beat in the eggs, evaporated milk, vanilla, cinnamon, nutmeg and salt until smooth."
    - "Pour into the crust and bake 45-55 minutes until the center is nearly set."
    - "Cool completely before slicing."
