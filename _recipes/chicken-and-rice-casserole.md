title: "Chicken and Rice Casserole"
slug: chicken-and-rice-casserole
date: 2026-01-01
category: Dinner
cuisine: "American"
description: "A creamy one-dish bake of chicken, rice and vegetables."
image: ""
recipeContent:
  prepTimeMinutes: 15
  cookTimeMinutes: 55
  servingsNumber: 6
  servingsUnit: Servings
  ingredients:
    - { amount: "1 1/2 lbs", item: "boneless chicken thighs, cubed" }
    - { amount: "1 1/2 cups", item: "long-grain white rice, uncooked" }
    - { amount: "1 can (10.5 oz)", item: "cream of chicken soup" }
    - { amount: "2 1/2 cups", item: "chicken broth" }
    - { amount: "1 cup", item: "frozen broccoli florets" }
    - { amount: "1/2 cup", item: "sour cream" }
    - { amount: "1 tsp", item: "garlic powder" }
    - { amount: "1 tsp", item: "salt" }
    - { amount: "1/2 tsp", item: "black pepper" }
    - { amount: "1 1/2 cups", item: "shredded cheddar" }
  steps:
    - "Heat the oven to 375°F and grease a 9x13-inch baking dish."
    - "Whisk the soup, broth, sour cream, garlic powder, salt and pepper in a bowl."
    - "Spread the rice and chicken in the dish, scatter the broccoli on top, and pour the liquid over everything."
    - "Cover tightly with foil and bake 45 minutes."
    - "Uncover, sprinkle with the cheddar and bake 8-10 minutes more until melted and the rice is tender."
    - "Rest 5 minutes and fluff before serving."
note: "Uncooked long-grain rice is right here. Instant or parboiled rice cooks differently."
