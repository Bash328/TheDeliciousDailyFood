date: 2026-07-06
category: Breakfast
tag: "Brunch"
description: "Thin, lacy crepes rolled around strawberries and raspberries, piled with softly whipped cream."
image: "berry-crepes-whipped-cream.jpg"
recipeContent:
  prepTimeMinutes: 20
  cookTimeMinutes: 15
  servingsNumber: 4
  servingsUnit: Servings
  ingredients:
    - { amount: "1 cup", item: "all-purpose flour" }
    - { amount: "2", item: "large eggs" }
    - { amount: "1 1/4 cups", item: "whole milk" }
    - { amount: "2 tbsp", item: "unsalted butter, melted, plus more for the pan" }
    - { amount: "1 tbsp", item: "granulated sugar" }
    - { amount: "1/4 tsp", item: "salt" }
    - { amount: "1 tsp", item: "vanilla extract" }
    - { amount: "1 cup", item: "heavy cream, chilled" }
    - { amount: "2 tbsp", item: "powdered sugar" }
    - { amount: "1 cup", item: "strawberries, sliced" }
    - { amount: "1 cup", item: "raspberries" }
  steps:
    - "Whisk flour, eggs, milk, melted butter, sugar, salt, and vanilla together until completely smooth. Let the batter rest 15 minutes."
    - "Heat a lightly buttered nonstick skillet over medium heat. Pour in a thin layer of batter, swirling to coat the pan, and cook 1-2 minutes per side until lightly golden. Stack cooked crepes between sheets of parchment."
    - "Whip the cream with the powdered sugar to soft peaks."
    - "Fill each crepe with a spoonful of whipped cream and a few berries, then fold or roll."
    - "Top with the remaining whipped cream and berries just before serving."
note: "Crepes keep well wrapped in the fridge for a day — reheat briefly in a dry skillet before filling."
