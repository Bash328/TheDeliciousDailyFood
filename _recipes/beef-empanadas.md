recipeContent:
  prepTimeMinutes: 45
  cookTimeMinutes: 50
  servingsNumber: 10
  servingsUnit: Empanadas
  ingredients:
    - { amount: "2 1/2 cups", item: "all-purpose flour" }
    - { amount: "12 tbsp (175 g)", item: "cold unsalted butter, cut into 1/2-inch cubes" }
    - { amount: "1 tsp", item: "kosher salt" }
    - { amount: "1", item: "egg yolk" }
    - { amount: "1/2 cup", item: "warm full-fat milk" }
    - { amount: "1 1/2 tbsp", item: "olive oil" }
    - { amount: "1/2", item: "onion, finely chopped" }
    - { amount: "1", item: "garlic clove, minced" }
    - { amount: "10 oz", item: "ground beef" }
    - { amount: "4 oz", item: "chorizo" }
    - { amount: "2 tsp", item: "tomato paste" }
    - { amount: "1 tsp", item: "fresh thyme, finely chopped" }
    - { amount: "1/2 tsp each", item: "dried oregano, cumin and paprika" }
    - { amount: "1/4 tsp", item: "cayenne pepper" }
    - { amount: "1/4 tsp", item: "kosher salt" }
    - { amount: "3/4 cup", item: "low-sodium chicken broth" }
    - { amount: "1/2 cup", item: "tomato passata or crushed tomatoes" }
    - { amount: "5 oz", item: "potato, peeled and cut into 1/3-inch cubes" }
    - { amount: "1/3 cup", item: "sliced green onion" }
    - { amount: "2", item: "hard-boiled eggs" }
    - { amount: "1/4 cup", item: "green olives, roughly chopped" }
    - { amount: "2", item: "eggs, separated (yolks whisked), for sealing and brushing" }
  steps:
    - "Chop the chorizo and blitz it with a stick blender to a paste."
    - "Cook the onion and garlic in the oil 2 minutes. Add the chorizo for 2 minutes, then the beef until no longer raw, then the tomato paste for 1 minute."
    - "Add the thyme, spices, salt, broth, passata and potato. Simmer gently 15 minutes until the filling is juicy but not watery and the potato is cooked. Stir in the green onion and cool completely (about 2 hours)."
    - "For the dough, whisk the milk and yolk. Pulse the flour, salt and butter in a food processor until the butter is in pea-size crumbs, add the milk mixture and blitz on low until a dough forms. Shape into two discs, wrap and chill 30 minutes."
    - "Heat the oven to 425°F. Roll one disc out to 1/8 inch thick and cut 6-inch rounds, keeping them chilled."
    - "Put 3 tbsp of cold filling on the top half of each round, spread flat, and add some chopped egg and olives, leaving a 1/2-inch border."
    - "Brush the edge with egg white, fold over, press out the air and seal, pleating or crimping with a fork."
    - "Bake on two trays, brushed with egg yolk, 20 minutes until golden and crisp on the bottom. Serve hot."
note: "Adapted from RecipeTin Eats' beef empanadas (4.93 stars from 40 votes). They freeze well, unbaked or baked."
