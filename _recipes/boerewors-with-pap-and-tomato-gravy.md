recipeContent:
  prepTimeMinutes: 15
  cookTimeMinutes: 45
  servingsNumber: 4
  servingsUnit: Servings
  ingredients:
    - { amount: "2 lbs", item: "boerewors sausage" }
    - { amount: "2 cups", item: "white maize meal (mealie meal)" }
    - { amount: "4 cups", item: "water" }
    - { amount: "1 tsp", item: "salt" }
    - { amount: "1 tbsp", item: "butter" }
    - { amount: "2 tbsp", item: "coconut oil or vegetable oil, for the gravy" }
    - { amount: "1", item: "onion, finely chopped" }
    - { amount: "5", item: "tomatoes, chopped" }
    - { amount: "1", item: "garlic clove, crushed" }
    - { amount: "1 tsp", item: "chili flakes" }
    - { amount: "1 tbsp", item: "brown sugar" }
    - { amount: "2 tbsp", item: "fruit chutney (such as Mrs Ball's)" }
    - { amount: "1 tbsp", item: "tomato paste" }
    - { amount: "To taste", item: "salt and ground pepper" }
  steps:
    - "Make the gravy first. Fry the onion in the oil until soft, then add the garlic, tomatoes, chili flakes, sugar, chutney and tomato paste."
    - "Cook on medium heat for 30 minutes, stirring every few minutes so it doesn't stick, then season with salt and pepper."
    - "Meanwhile cook the boerewors on a grill or in a pan over medium heat, turning, for 20-25 minutes until browned and cooked through."
    - "For the pap, bring the water and salt to a boil. Stir in the maize meal gradually, reduce the heat, cover and cook about 30 minutes, stirring every so often, until stiff and cooked through. Stir in the butter."
    - "Serve the pap with the boerewors and spoon the gravy over."
note: "The tomato gravy is adapted from East Coast Radio's Tocka Blog recipe. The pap is a standard stiff pap, and the page I used doesn't show a rating."
