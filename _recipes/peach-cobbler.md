---
title: "Peach Cobbler"
slug: peach-cobbler
date: 2026-01-01
category: Dessert
tag: "Classic"
description: "Juicy, lemony peaches under golden, buttery biscuit topping."
image: ""
recipeContent:
  prepTimeMinutes: 30
  cookTimeMinutes: 45
  servingsNumber: 12
  servingsUnit: Servings
  ingredients:
    - { amount: "10 cups", item: "peeled, sliced peaches (fresh, or thawed frozen)" }
    - { amount: "1 tbsp", item: "butter, melted" }
    - { amount: "2 tbsp", item: "lemon juice" }
    - { amount: "1 cup", item: "granulated sugar" }
    - { amount: "1/4 cup", item: "all-purpose flour, for thickening" }
    - { amount: "2 cups", item: "all-purpose flour, for the topping" }
    - { amount: "1/2 cup", item: "granulated sugar, for the topping" }
    - { amount: "2 1/2 tsp", item: "baking powder" }
    - { amount: "1/2 tsp", item: "salt" }
    - { amount: "6 tbsp", item: "butter, melted" }
    - { amount: "1/2 cup", item: "milk" }
    - { amount: "1", item: "large egg" }
    - { amount: "1 1/2 tsp", item: "almond extract (or vanilla)" }
    - { amount: "3 to 4 tsp", item: "coarse sugar or cinnamon sugar, for sprinkling" }
  steps:
    - "Heat the oven to 425°F and lightly butter a 9x13-inch baking dish."
    - "Toss the peaches with the melted butter and lemon juice. Mix the sugar and thickening flour together, sprinkle over the peaches and toss until evenly coated. Scoop into the dish."
    - "Whisk the topping flour, sugar, baking powder and salt in a bowl. In another bowl whisk the melted butter, milk, egg and almond extract. Stir the wet into the dry until just combined."
    - "Dollop the topping over the peaches in 12 spoonfuls, leaving about 1/2 inch between them so the fruit can bubble up. Use any extra to fill gaps, and sprinkle with the coarse sugar."
    - "Bake 20 minutes, then reduce the oven to 375°F and bake 25 minutes more, until the topping is deep golden brown and the filling is bubbling."
    - "Cool for 15 minutes and serve warm or at room temperature, with vanilla ice cream if you like."
note: "Proportions adapted from King Arthur Baking's Easy Peach Cobbler (4.6 stars, 36 reviews). Keep the topping a deep golden brown so the center biscuits bake through. Refrigerate leftovers up to 5 days."
