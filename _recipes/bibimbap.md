description: "A rice bowl topped with seasoned vegetables, a fried egg and spicy gochujang sauce."
image: ""
recipeContent:
  prepTimeMinutes: 30
  cookTimeMinutes: 10
  servingsNumber: 2
  servingsUnit: Servings
  ingredients:
    - { amount: "1/2", item: "English cucumber, thinly sliced" }
    - { amount: "1/2 tsp", item: "rice vinegar" }
    - { amount: "1 1/4 tsp", item: "toasted sesame oil, divided" }
    - { amount: "1 cup", item: "fresh mung bean sprouts" }
    - { amount: "1 cup", item: "shredded carrots" }
    - { amount: "4 cups", item: "baby spinach" }
    - { amount: "1/2 tsp", item: "tamari or soy sauce" }
    - { amount: "2 cups", item: "cooked short-grain white rice" }
    - { amount: "2", item: "fried eggs (or 1 cup cubed baked tofu)" }
    - { amount: "4 oz", item: "sautéed shiitake mushrooms (optional)" }
    - { amount: "2 tbsp", item: "gochujang, for the sauce" }
    - { amount: "1 tbsp", item: "rice vinegar, for the sauce" }
    - { amount: "2 tsp", item: "maple syrup, for the sauce" }
    - { amount: "2 tsp", item: "toasted sesame oil, for the sauce" }
    - { amount: "1-2 tbsp", item: "water, to thin the sauce" }
    - { amount: "To serve", item: "sesame seeds, sea salt, kimchi and scallions" }
  steps:
    - "Whisk the gochujang sauce ingredients, thinning with water until pourable."
    - "Toss the cucumber with the rice vinegar, 1/4 tsp of the sesame oil and a pinch of salt and set aside."
    - "Boil the bean sprouts for 1 minute, drain and set aside."
    - "Heat 1/2 tsp sesame oil in a skillet, cook the carrots with a pinch of salt for 1-2 minutes until slightly soft and remove. Heat the remaining 1/2 tsp oil, wilt the spinach with the tamari for 30 seconds, then squeeze out excess moisture."
    - "Divide the rice between two bowls and arrange the vegetables around it. Top with a fried egg (or tofu) and mushrooms."
    - "Sprinkle with sesame seeds, drizzle with the sauce and serve with kimchi and scallions. Stir everything together before eating."
note: "Adapted from Love and Lemons' bibimbap (5 stars from 52 votes). That recipe's sauce uses gochujang, rice vinegar, sesame oil and maple syrup. The sauce quantities here are my own."
