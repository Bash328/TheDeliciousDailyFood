    - { amount: "2 tsp", item: "soy sauce" }
    - { amount: "2 tsp", item: "white sugar" }
    - { amount: "2 tsp", item: "finely minced garlic" }
    - { amount: "1/2 tsp", item: "black pepper" }
    - { amount: "1/4 cup", item: "soy sauce, for the sauce" }
    - { amount: "2 tsp", item: "white sugar" }

    - { amount: "1 1/2 tbsp", item: "sesame oil" }
    - { amount: "1/2 tsp", item: "kosher salt" }
    - { amount: "1/2 tsp", item: "black pepper" }
    - { amount: "8 oz (250 g)", item: "dried sweet potato noodles (dangmyeon)" }
    - { amount: "4 tbsp", item: "vegetable oil, divided" }
    - { amount: "1 tsp", item: "kosher salt, divided" }
    - { amount: "1", item: "onion, cut into 1/4-inch wedges" }
    - { amount: "3", item: "green onions, cut into 2-inch lengths, white and green parts separated" }
    - { amount: "7 oz (200 g)", item: "fresh shiitake mushrooms, stems removed, sliced" }
    - { amount: "2", item: "carrots, cut into thin batons" }
    - { amount: "1", item: "red bell pepper, sliced" }
    - { amount: "4 1/2 cups", item: "baby spinach, tightly packed" }
    - { amount: "2 tbsp", item: "white sesame seeds" }
  steps:
    - "Mix the beef with the marinade ingredients and set aside 15-20 minutes."
    - "Mix the sauce ingredients in a very large bowl."
    - "Cook the noodles per the package (about 8 minutes), drain, rinse briefly and shake off the water. Put them in the bowl with the sauce but don't mix yet."
    - "Batch 1: heat 2 tbsp oil in a large pan over high heat and cook the onion, white green-onion parts and mushrooms with 1/2 tsp salt for 2 1/2-3 minutes until just softening. Pour on top of the noodles, still without mixing."
    - "Batch 2: with 1 tbsp oil, cook the carrot and bell pepper 1 1/2 minutes, then add the spinach, green onion tops and the remaining 1/2 tsp salt for 1 1/2 minutes until wilted. Add to the bowl."
    - "Heat the last 1 tbsp oil and cook the beef 1 1/2 minutes until lightly golden and just cooked. Add to the bowl."
    - "Add most of the sesame seeds and now toss everything together well. Top with the rest of the seeds and serve warm, not piping hot."
note: "Adapted from RecipeTin Eats' japchae (4.89 stars from 43 votes). Keeping the noodles and vegetables un-mixed until the end stops the vegetables from overcooking."
