    - { amount: "4", item: "garlic cloves, peeled and smashed" }
    - { amount: "2", item: "habanero or scotch bonnet peppers, stems removed" }
    - { amount: "1 1/2 inch", item: "piece fresh ginger, peeled and sliced" }
    - { amount: "1/3 cup", item: "fresh lime juice" }
    - { amount: "1/4 cup", item: "soy sauce" }

    - { amount: "1/2 tsp", item: "ground cinnamon" }
    - { amount: "1/2 tsp", item: "ground nutmeg" }
  steps:
    - "Put the chicken in a large resealable bag."
    - "Pulse everything else in a food processor until coarsely chopped. Pour it over the chicken, seal, and rub the marinade in. Refrigerate 3-24 hours."
    - "To bake: heat the oven to 375°F and line a baking sheet with foil. Remove the chicken from the marinade, space it out on the pan and bake 45-50 minutes until cooked through, broiling the last few minutes for browning."
    - "To grill: heat the grill to medium-high (about 400°F), oil the grates and grill the chicken, turning, about 30 minutes, lowering the heat if it browns too quickly."
    - "Rest a few minutes before serving."
