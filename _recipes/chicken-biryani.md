    - { amount: "1.1 lbs", item: "chicken (thighs, drumsticks or a mix), skinless" }
    - { amount: "3 tbsp", item: "plain yogurt" }
    - { amount: "1 1/4 tbsp", item: "ginger-garlic paste" }
    - { amount: "1/2 to 3/4 tsp", item: "salt" }
    - { amount: "1/4 tsp", item: "turmeric" }
    - { amount: "1/2 to 1 tsp", item: "red chili powder or paprika" }
    - { amount: "1/2 to 1 tbsp", item: "garam masala" }
    - { amount: "1 tbsp", item: "lemon juice (optional)" }
    - { amount: "1", item: "bay leaf" }
    - { amount: "4", item: "green cardamom pods" }
    - { amount: "6", item: "cloves" }
    - { amount: "1 inch", item: "cinnamon stick" }
    - { amount: "1", item: "star anise" }
    - { amount: "3/4 tsp", item: "caraway or cumin seeds" }
    - { amount: "2 cups", item: "aged basmati rice" }
    - { amount: "2 tbsp", item: "ghee or oil" }
    - { amount: "1", item: "large onion, thinly sliced" }
    - { amount: "1/4 to 1/2 cup", item: "chopped mint leaves" }
    - { amount: "1", item: "green chili, slit" }
    - { amount: "1/4 cup", item: "plain yogurt, for the pot" }
    - { amount: "1 tsp", item: "garam masala, for the pot" }
    - { amount: "3 cups", item: "water, plus more if needed" }
    - { amount: "3/4 tsp", item: "salt, for the water" }
    - { amount: "2 tbsp", item: "fried onions (optional)" }
    - { amount: "Pinch", item: "saffron soaked in 2 tbsp hot milk (optional)" }
  steps:
    - "Mix the 3 tbsp yogurt, ginger-garlic paste, salt, garam masala, turmeric, lemon juice and chili powder. Slash the chicken, coat it in the marinade, cover and refrigerate for at least 1 hour or overnight."
    - "Rinse the rice three times and soak 30 minutes, then drain."
    - "Heat the ghee in a heavy pot. Add the bay leaf, cardamom, cloves, cinnamon, star anise and caraway and let them sizzle."
    - "Add the onion and fry, stirring, until evenly light brown."
    - "Add the chicken and sauté 5 minutes, then cover and cook on low until tender. Cook off any extra moisture, then taste for salt."
    - "Stir in the 1/4 cup yogurt, half the mint, the green chili, the extra garam masala and optional chili powder. Spread the chicken evenly across the bottom of the pot."
    - "Layer the drained rice over the chicken."
    - "Bring the water to a boil with the salt (it should taste slightly salty). Pour it carefully over the rice. Scatter with the rest of the mint, the fried onions and the saffron milk if using."
    - "Cover tightly and cook on medium heat about 15 minutes, until the rice is cooked but still grainy. If it seems undercooked and dry, add 1/4 to 1/2 cup more boiling water and cook a few more minutes."
    - "Rest 5 minutes, fluff with a fork and serve from the top down, so each portion has rice and chicken. Serve with raita."
note: "Adapted from Indian Healthy Recipes' chicken biryani (4.99 stars from 1,674 votes). Use aged basmati so the grains stay separate."
