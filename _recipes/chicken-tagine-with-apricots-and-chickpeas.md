    - { amount: "1 cup", item: "dried apricots, halved" }
    - { amount: "6 (7 oz each)", item: "bone-in, skin-on chicken thighs" }
    - { amount: "3/4 tsp", item: "salt" }
    - { amount: "2 tbsp", item: "olive oil" }
    - { amount: "1", item: "onion, thinly sliced" }
    - { amount: "2", item: "garlic cloves, finely minced" }
    - { amount: "1", item: "cinnamon stick" }
    - { amount: "14 oz", item: "crushed tomatoes (1 can)" }
    - { amount: "14 oz", item: "canned chickpeas, drained" }
    - { amount: "1 tbsp", item: "preserved lemon skin, finely minced" }
    - { amount: "2 1/2 cups", item: "low-sodium chicken stock" }
    - { amount: "1 tsp", item: "salt, for the spice mix" }
    - { amount: "3/4 tsp", item: "ground cumin" }
    - { amount: "3/4 tsp", item: "ground ginger" }
    - { amount: "3/4 tsp", item: "black pepper" }
    - { amount: "1/2 tsp", item: "allspice" }
    - { amount: "1/4 tsp", item: "cinnamon" }
    - { amount: "1/4 tsp", item: "ground coriander" }
    - { amount: "1/8 tsp", item: "ground cloves" }
    - { amount: "To serve", item: "couscous, 2 tbsp chopped cilantro, 1/3 cup toasted slivered almonds" }
  steps:
    - "Soak the apricots in boiling water for 30 minutes to plump them, then drain. Mix the 1 tsp salt and ground spices together."
    - "Sprinkle the chicken with 3/4 tsp salt. Heat the oil in a large deep skillet over high heat and brown the chicken skin-side down 8-10 minutes until deep golden, then 1 minute on the other side. Set aside."
    - "Pour off all but 2 tbsp of fat. Lower the heat to medium and cook the onion 3 minutes, then the garlic 1 minute. Stir in the spice mix for 30 seconds."
    - "Add the cinnamon stick, tomatoes, chickpeas, apricots, preserved lemon and stock, then set the chicken on top, skin-side up."
    - "Bring to a simmer, cover and cook 5 minutes. Uncover and cook 20 minutes more, until the chicken reaches at least 158°F."
    - "Rest 5 minutes and serve over couscous with cilantro and almonds."
note: "Adapted from RecipeTin Eats' chicken tagine (4.91 stars from 66 votes). No tagine pot needed: a deep skillet does the job."
