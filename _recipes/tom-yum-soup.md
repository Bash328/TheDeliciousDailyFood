description: "A hot and sour Thai soup of shrimp, lemongrass, galangal, lime leaves and lime juice."
image: ""
recipeContent:
  prepTimeMinutes: 15
  cookTimeMinutes: 20
  servingsNumber: 2
  servingsUnit: Bowls
  ingredients:
    - { amount: "10 oz", item: "whole prawns or shrimp, with heads and shells on" }
    - { amount: "3 cups", item: "water" }
    - { amount: "1/2 cup", item: "low-sodium chicken stock" }
    - { amount: "2 stalks", item: "lemongrass, outer layers peeled" }
    - { amount: "1.5 cm piece", item: "galangal, cut into 4 slices" }
    - { amount: "5", item: "kaffir lime leaves, torn" }
    - { amount: "2", item: "Thai chilies" }
    - { amount: "3", item: "garlic cloves" }
    - { amount: "4 oz", item: "oyster mushrooms" }
    - { amount: "1", item: "roma tomato, cut into wedges" }
    - { amount: "1/2", item: "white onion, cut into wedges" }
    - { amount: "1 tsp", item: "sugar" }
    - { amount: "3 tbsp", item: "fish sauce" }
    - { amount: "3 tbsp", item: "lime juice" }
    - { amount: "To serve", item: "fresh cilantro" }
    - { amount: "1 1/2 tbsp", item: "Thai roasted chili paste (nam prik pao), for the creamy version" }
    - { amount: "1/3 cup", item: "evaporated milk, for the creamy version" }
  steps:
    - "Peel the prawns, keeping the heads and shells, and set the meat aside."
    - "Bruise the garlic, chilies and lemongrass with a mallet. Put them in a pot with the prawn heads and shells, the torn lime leaves, galangal, stock and water."
    - "Bring to a simmer, cover and simmer on medium for 10 minutes. Strain the broth and return it to the pot over low heat."
    - "Add the onion and mushrooms for 3 minutes, then the tomato for 1 minute, then the prawns for 2 minutes until just cooked."
    - "Stir in the sugar and fish sauce for 1 minute, then add the lime juice. Taste and adjust the sweet, salty and sour."
    - "For the creamy version, stir in the chili paste and evaporated milk along with the sugar."
    - "Serve with cilantro and fresh chilies."
note: "Adapted from RecipeTin Eats' tom yum soup (4.96 stars from 70 votes). Using the prawn shells for the stock builds the depth."
