description: "Thin rice noodles stir-fried with shrimp, char siu pork, egg and peppers in a curry-spiced sauce."

recipeContent:
  prepTimeMinutes: 15
  cookTimeMinutes: 10
  servingsNumber: 2
  servingsUnit: Servings
  ingredients:
    - { amount: "2 tbsp", item: "soy sauce" }
    - { amount: "2 tbsp", item: "Shaoxing (Chinese cooking) wine" }
    - { amount: "2 1/2 tsp", item: "curry powder" }
    - { amount: "1/2 tsp", item: "sugar" }
    - { amount: "1/2 tsp", item: "white pepper" }
    - { amount: "100 g (3 oz)", item: "dried rice vermicelli" }
    - { amount: "2 tbsp", item: "peanut oil, divided" }
    - { amount: "8-10", item: "medium raw shrimp, peeled and deveined" }
    - { amount: "2", item: "eggs, beaten" }
    - { amount: "1/2 medium", item: "onion, thinly sliced" }
    - { amount: "4", item: "garlic cloves, minced" }
    - { amount: "1 tsp", item: "fresh ginger, grated" }
    - { amount: "250 g (1/2 lb)", item: "Chinese barbecue pork (char siu), thinly sliced" }
    - { amount: "1 cup", item: "red bell pepper, sliced" }
    - { amount: "2 tsp", item: "hot green chili, thinly sliced (optional)" }
  steps:
    - "Mix the soy sauce, Shaoxing wine, curry powder, sugar and white pepper in a small bowl."
    - "Soak the vermicelli in just-boiled water as the packet says, then drain well."
    - "Heat 1 tbsp of the oil in a wok over medium heat and cook the shrimp until just done, 2-3 minutes. Lift them out."
    - "Pour in the eggs and swirl into a thin omelette. When set, roll it up, take it out and slice into ribbons."
    - "Add the rest of the oil and cook the garlic, ginger and onion for 2 minutes, then the bell pepper for 1 minute more."
    - "Add the noodles and sauce and toss, then return the egg, shrimp and pork with the chili, if using. Toss for 1-2 minutes until everything is coated and hot. Serve at once."
note: "Adapted from RecipeTin Eats' Singapore noodles (4.97 stars from 130 votes). No char siu? Use leftover roast pork or chicken."
