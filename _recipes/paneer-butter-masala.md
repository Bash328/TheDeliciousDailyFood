---
title: "Paneer Butter Masala"
date: 2026-11-25
category: Dinner
cuisine: "Indian"
description: "Soft paneer in a silky, mildly spiced tomato, cashew and butter gravy, finished with cream and kasuri methi."
image: ""
recipeContent:
  prepTimeMinutes: 15
  cookTimeMinutes: 30
  servingsNumber: 4
  servingsUnit: Servings
  ingredients:
    - { amount: "1 tbsp", item: "oil" }
    - { amount: "2", item: "green cardamom pods" }
    - { amount: "1 cup (130 g)", item: "onion, sliced" }
    - { amount: "1 inch", item: "ginger, sliced" }
    - { amount: "5-6 large", item: "garlic cloves" }
    - { amount: "2 cups (350 g)", item: "tomatoes, sliced" }
    - { amount: "15", item: "whole cashews" }
    - { amount: "1 tsp", item: "salt, to taste" }
    - { amount: "3/4-1 tsp", item: "Kashmiri red chili powder (or paprika)" }
    - { amount: "3/4-1 tsp", item: "garam masala" }
    - { amount: "1 tsp", item: "coriander powder" }
    - { amount: "1 1/2 cups", item: "water, divided" }
    - { amount: "2 tbsp", item: "unsalted butter" }
    - { amount: "1 small", item: "bay leaf, a small cinnamon stick and 3 cloves (optional)" }
    - { amount: "250-300 g", item: "paneer, cut into 2 cm cubes" }
    - { amount: "1/2 tbsp", item: "kasuri methi (dried fenugreek leaves), crushed" }
    - { amount: "1 tsp", item: "sugar (optional)" }
    - { amount: "3-4 tbsp", item: "heavy cream" }
    - { amount: "1-2 tbsp", item: "cilantro, chopped, for garnish" }
  steps:
    - "Heat the oil and cook the cardamom, onion, ginger and garlic for 4-5 minutes, until the onion turns translucent."
    - "Add the tomatoes, cashews and salt. Cover and cook on medium until the tomatoes collapse, about 7 minutes."
    - "Stir in the chili powder, coriander powder and garam masala and cook 3-4 minutes until fragrant. Let cool, then blend with 1 cup cold water until completely smooth."
    - "Melt the butter in the same pan over low heat with the whole spices, if using. Pour the puree in through a strainer, pressing it through."
    - "Add 1/2 cup more water, cover and simmer on medium for 10-12 minutes, stirring now and then, until slightly thick but still pourable."
    - "Take out the whole spices, adjust salt, and stir in the sugar, kasuri methi and paneer. Cover and cook 2-3 minutes on low, then stir in the cream. Garnish with cilantro and serve with rice or naan."
note: "Adapted from Indian Healthy Recipes' paneer butter masala (4.98 stars from 1,600 votes). Straining the puree is what makes the gravy so smooth."
---
