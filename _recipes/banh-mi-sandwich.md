---
title: "Banh Mi Sandwich"
slug: banh-mi-sandwich
date: 2026-01-01
category: Lunch
cuisine: "Vietnamese"
description: "Crisp baguette with savory pork, pickled carrot and daikon, cilantro and chili."
image: ""
recipeContent:
  prepTimeMinutes: 25
  cookTimeMinutes: 15
  servingsNumber: 4
  servingsUnit: Sandwiches
  ingredients:
    - { amount: "1 lb", item: "pork tenderloin, thinly sliced" }
    - { amount: "2 tbsp", item: "soy sauce" }
    - { amount: "1 tbsp", item: "fish sauce" }
    - { amount: "1 tbsp", item: "honey" }
    - { amount: "2", item: "garlic cloves, minced" }
    - { amount: "1 tbsp", item: "vegetable oil" }
    - { amount: "4", item: "small baguettes or sub rolls" }
    - { amount: "1/4 cup", item: "mayonnaise" }
    - { amount: "1 cup", item: "carrot and daikon, julienned" }
    - { amount: "1/4 cup", item: "rice vinegar" }
    - { amount: "1 tbsp", item: "sugar" }
    - { amount: "1/2", item: "cucumber, sliced" }
    - { amount: "1/2 cup", item: "fresh cilantro" }
    - { amount: "1", item: "jalapeño, sliced" }
  steps:
    - "Marinate the pork in the soy sauce, fish sauce, honey and garlic for 15 minutes."
    - "Toss the carrot and daikon with the vinegar, sugar and a pinch of salt and let pickle for 20 minutes."
    - "Cook the pork in the oil in a hot skillet 3-4 minutes until caramelized and cooked through."
    - "Toast the baguettes, spread with mayonnaise, and fill with pork, pickles, cucumber, cilantro and jalapeño."
note: "The quick pickles keep a week in the fridge."
