category: Dinner
cuisine: "South African"
description: "Spiced, lightly sweet curried mince baked under a golden egg custard, South Africa's national dish."
image: ""
recipeContent:
  prepTimeMinutes: 10
  cookTimeMinutes: 60
  servingsNumber: 4
  servingsUnit: Servings
  ingredients:
    - { amount: "1 tbsp", item: "butter" }
    - { amount: "2", item: "medium onions, diced" }
    - { amount: "2", item: "garlic cloves, crushed" }
    - { amount: "1 slice", item: "bread, crusts removed" }
    - { amount: "1 cup", item: "milk" }
    - { amount: "1 tbsp", item: "curry powder" }
    - { amount: "1/2 tsp", item: "ground turmeric" }
    - { amount: "1/2 tsp", item: "ground cumin" }
    - { amount: "1 1/2 lbs", item: "ground beef or lamb (or a mix)" }
    - { amount: "1", item: "apple, peeled and grated" }
    - { amount: "1/4 cup", item: "raisins" }
    - { amount: "1 tbsp", item: "lemon juice" }
    - { amount: "1 tbsp", item: "Worcestershire sauce" }
    - { amount: "2", item: "eggs" }
    - { amount: "1", item: "bay leaf (optional)" }
  steps:
    - "Heat the oven to 325°F. Soak the bread in the milk."
    - "Melt the butter in a large skillet and cook the onions and garlic about 5 minutes until soft."
    - "Stir in the curry powder, turmeric and cumin for a minute, then add the meat and cook, stirring, until browned."
    - "Squeeze the milk out of the bread (keep the milk) and add the bread to the pan with the apple and raisins. Remove from the heat and mix in the lemon juice, Worcestershire and 1 egg."
    - "Press the mixture into a casserole dish. Whisk the remaining egg into the reserved milk, pour it over the top and lay the bay leaf on it if you have one."
    - "Bake 40-50 minutes until the custard is set and lightly browned."
    - "Serve with yellow rice and chutney."
note: "Adapted from Caroline's Cooking's bobotie (4.45 stars from 9 ratings; a small sample). The recipe is a classic Cape Malay dish, so many families make their own version."
