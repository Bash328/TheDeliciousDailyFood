  servingsNumber: 4
  servingsUnit: Servings
  ingredients:
    - { amount: "1 tbsp", item: "whole Sichuan peppercorns (for 1 tsp ground)" }
    - { amount: "21 oz (600g)", item: "silken tofu, cut into 1.5 cm squares" }
    - { amount: "2 1/2 cups", item: "water" }
    - { amount: "1 tsp", item: "salt" }
    - { amount: "1/2 tsp", item: "dark soy sauce" }
    - { amount: "1 tbsp", item: "neutral oil" }
    - { amount: "3.5 oz (100g)", item: "ground pork or beef" }
    - { amount: "1 tsp", item: "light soy sauce" }
    - { amount: "1/4 cup", item: "neutral oil, for the sauce" }
    - { amount: "2 tbsp", item: "garlic, finely minced" }
    - { amount: "2 1/2 tbsp", item: "ginger, finely minced" }
    - { amount: "1 tbsp", item: "preserved black beans, chopped" }
    - { amount: "1 tbsp", item: "spicy broad bean paste (Pixian doubanjiang)" }
    - { amount: "1 tsp", item: "light soy sauce" }
    - { amount: "2 tsp", item: "pure chili powder" }
    - { amount: "1 tsp", item: "smoked or sweet paprika" }
    - { amount: "1 tsp", item: "sugar" }
    - { amount: "1", item: "green onion, finely sliced" }
    - { amount: "3/4 cup", item: "low-sodium beef broth" }
    - { amount: "1 tsp", item: "toasted sesame oil" }
    - { amount: "2 tsp", item: "cornstarch mixed with 1/4 cup water" }
    - { amount: "To serve", item: "steamed white rice" }
  steps:
    - "Toast the Sichuan peppercorns in a dry pan for 2-3 minutes, grind them finely and sift out the husks. Measure 1 tsp."
    - "Bring the water, dark soy and salt to a boil, add the tofu and simmer 3 minutes. Lift it out gently and set aside."
    - "Heat 1 tbsp oil in a wok on high and cook the pork until no pink remains, then 2 more minutes until golden. Stir in 1 tsp light soy sauce and remove."
    - "Lower the heat, add the remaining oil and cook the garlic and ginger 90 seconds. Add the black beans and broad bean paste and cook 3 minutes, stirring. Add the chili powder and paprika for 30 seconds."
    - "Pour in the broth and 1 tsp soy sauce, bring to a bubble, then add the tofu gently. Simmer 10 minutes, nudging rather than stirring so it doesn't break."
    - "Add the sugar, pork and 1/2 tsp Sichuan pepper. Pour the cornstarch slurry over the surface and stir gently until thickened."
    - "Stir in most of the green onion and the sesame oil. Top with the remaining Sichuan pepper and onion and serve over rice."
note: "Adapted from RecipeTin Eats' mapo tofu (4.93 stars from 28 votes). Sichuan peppercorns give the signature numbing tingle, and Pixian broad bean paste is worth seeking out."
