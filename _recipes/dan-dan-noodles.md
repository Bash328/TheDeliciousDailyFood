image: ""
recipeContent:
  prepTimeMinutes: 20
  cookTimeMinutes: 70
  servingsNumber: 6
  servingsUnit: Bowls
  ingredients:
    - { amount: "2 tbsp", item: "Sichuan peppercorns" }
    - { amount: "1", item: "cinnamon stick" }
    - { amount: "2", item: "star anise" }
    - { amount: "1 cup", item: "neutral oil, for the chili oil" }
    - { amount: "1/4 cup", item: "crushed red pepper flakes" }
    - { amount: "3 tsp", item: "oil, divided" }
    - { amount: "8 oz", item: "ground pork" }
    - { amount: "2 tsp", item: "sweet bean sauce or hoisin sauce" }
    - { amount: "2 tsp", item: "Shaoxing wine" }
    - { amount: "1 tsp", item: "dark soy sauce" }
    - { amount: "3/4 tsp", item: "five-spice powder, divided" }
    - { amount: "1/3 cup", item: "sui mi ya cai (Sichuan pickled greens)" }
    - { amount: "2 tbsp", item: "Chinese sesame paste or tahini" }
    - { amount: "3 tbsp", item: "soy sauce" }
    - { amount: "2 tsp", item: "sugar" }
    - { amount: "1/2 tsp", item: "ground Sichuan peppercorns" }
    - { amount: "2", item: "garlic cloves, very finely minced" }
    - { amount: "1 lb", item: "fresh or dried wheat noodles, medium thickness" }
    - { amount: "1 small bunch", item: "bok choy, choy sum or spinach" }
    - { amount: "For garnish", item: "chopped peanuts and scallions" }
  steps:
    - "Chili oil: warm the whole Sichuan peppercorns, cinnamon, star anise and 1 cup oil in a small pot over medium-low heat to 160°C (325°F), then turn off. After 6-7 minutes lift out the spices, stir in the chili flakes and let it cool. You'll have extra; keep it in a jar in the fridge."
    - "Pork: brown the pork in 1 tsp oil in a wok over medium heat. Add the sweet bean sauce, Shaoxing wine, dark soy and 1/2 tsp five-spice and cook until dry. Set aside. Fry the pickled greens in the other 2 tsp oil for a few minutes."
    - "Sauce: mix the sesame paste, soy sauce, sugar, the remaining 1/4 tsp five-spice, ground Sichuan pepper, garlic and 1/2 cup of the chili oil. Loosen with about 1/4 cup hot noodle water and adjust to taste."
    - "Cook the noodles as the packet says and drain. Blanch the greens in the same water."
    - "Divide the sauce among bowls, add noodles and greens, then top with the pork, pickled greens, peanuts and scallions. Mix well at the table."
note: "Adapted from The Woks of Life's dan dan noodles (4.94 stars from 210 votes). Most of the time is the chili oil cooling. With a jar of chili oil on hand, it's a 30-minute dinner."
