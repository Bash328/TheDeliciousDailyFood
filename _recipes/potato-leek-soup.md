date: 2026-01-01
category: Soup
cuisine: "French"
description: "Silky and mild, with buttery leeks and tender potatoes."
image: ""
recipeContent:
  prepTimeMinutes: 15
  cookTimeMinutes: 35
  servingsNumber: 6
  servingsUnit: Bowls
  ingredients:
    - { amount: "4 tbsp", item: "butter" }
    - { amount: "3", item: "large leeks, white and light green parts, sliced" }
    - { amount: "3", item: "garlic cloves, minced" }
    - { amount: "1 1/2 lbs", item: "Yukon gold potatoes, peeled and cubed" }
    - { amount: "4 cups", item: "chicken or vegetable broth" }
    - { amount: "1 tsp", item: "salt" }
    - { amount: "1/4 tsp", item: "black pepper" }
    - { amount: "1/2 cup", item: "heavy cream" }
    - { amount: "2 tbsp", item: "fresh chives, chopped" }
  steps:
    - "Melt the butter in a large pot over medium heat. Cook the leeks 8 minutes until soft but not browned. Add the garlic."
    - "Add the potatoes, broth, salt and pepper, and simmer 20 minutes until the potatoes are tender."
    - "Blend with an immersion blender until smooth, then stir in the cream."
    - "Serve topped with chives."
note: "Rinse the sliced leeks well. Grit hides between the layers."
