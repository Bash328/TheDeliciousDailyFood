title: "Chicken Parmesan"
slug: chicken-parmesan
date: 2026-01-01
category: Dinner
cuisine: "Italian"
description: "Crispy breaded chicken cutlets topped with marinara and melted mozzarella."
image: ""
recipeContent:
  prepTimeMinutes: 20
  cookTimeMinutes: 25
  servingsNumber: 4
  servingsUnit: Servings
  ingredients:
    - { amount: "2", item: "large chicken breasts, sliced in half into 4 cutlets" }
    - { amount: "1 tsp", item: "salt" }
    - { amount: "1/2 cup", item: "all-purpose flour" }
    - { amount: "2", item: "eggs, beaten" }
    - { amount: "1 cup", item: "panko breadcrumbs" }
    - { amount: "1/2 cup", item: "grated Parmesan" }
    - { amount: "1/2 cup", item: "olive oil, for frying" }
    - { amount: "1 1/2 cups", item: "marinara sauce" }
    - { amount: "1 1/2 cups", item: "shredded mozzarella" }
    - { amount: "To serve", item: "fresh basil" }
  steps:
    - "Heat the oven to 425°F. Pound the cutlets to an even 1/2-inch thickness and season with salt."
    - "Set up three dishes: flour, beaten eggs, and panko mixed with the Parmesan. Coat each cutlet in that order."
    - "Fry in the hot oil over medium-high heat 3 minutes per side until golden. Transfer to a baking sheet."
    - "Spoon marinara over each cutlet and top with mozzarella."
    - "Bake 10-12 minutes until the cheese is melted and the chicken is 165°F inside."
    - "Top with basil and serve with spaghetti."
