title: "Oven Baby Back Ribs"
slug: oven-baby-back-ribs
date: 2026-01-01
category: Dinner
cuisine: "American"
description: "Fall-off-the-bone ribs with a sticky barbecue glaze, made entirely in the oven."
image: ""
recipeContent:
  prepTimeMinutes: 15
  cookTimeMinutes: 165
  servingsNumber: 4
  servingsUnit: Servings
  ingredients:
    - { amount: "2 racks", item: "baby back ribs (about 4 lbs)" }
    - { amount: "2 tbsp", item: "brown sugar" }
    - { amount: "1 tbsp", item: "smoked paprika" }
    - { amount: "1 tbsp", item: "garlic powder" }
    - { amount: "1 tbsp", item: "onion powder" }
    - { amount: "2 tsp", item: "salt" }
    - { amount: "1 tsp", item: "black pepper" }
    - { amount: "1/2 tsp", item: "cayenne pepper" }
    - { amount: "1 cup", item: "barbecue sauce" }
  steps:
    - "Heat the oven to 275°F. Pull the thin membrane off the back of each rack with a paper towel."
    - "Mix the sugar, paprika, garlic powder, onion powder, salt, pepper and cayenne and rub it all over the ribs."
    - "Wrap each rack tightly in foil, place on a baking sheet and bake 2 1/2 hours until tender."
    - "Unwrap, brush generously with barbecue sauce and set under a hot broiler 3-5 minutes, watching closely, until sticky and caramelized."
    - "Rest 5 minutes, then slice between the bones."
note: "The ribs are done when the meat has pulled back from the ends of the bones."
