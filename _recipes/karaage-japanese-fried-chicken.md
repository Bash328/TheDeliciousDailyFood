title: "Karaage (Japanese Fried Chicken)"

category: Dinner
cuisine: "Japanese"
description: "Juicy chicken thigh pieces marinated in soy, ginger and garlic, then double-fried in a light, crackly starch coating."
image: ""
recipeContent:
  prepTimeMinutes: 15
  cookTimeMinutes: 15
  servingsNumber: 4
  servingsUnit: Servings
  ingredients:
    - { amount: "1 1/2 lb", item: "boneless, skin-on chicken thighs, cut into 5 cm pieces" }
    - { amount: "1/2 tsp", item: "kosher salt" }
    - { amount: "1/8 tsp", item: "black pepper" }
    - { amount: "1/2 tsp", item: "fresh ginger, grated, with its juice" }
    - { amount: "1", item: "garlic clove, minced" }
    - { amount: "1/2-1 tbsp", item: "soy sauce" }
    - { amount: "1/2 tbsp", item: "sake (or dry sherry)" }
    - { amount: "1/2 tsp", item: "toasted sesame oil" }
    - { amount: "2 tbsp", item: "potato starch or cornstarch, plus more if needed" }
    - { amount: "2 tbsp", item: "all-purpose flour, plus more if needed" }
    - { amount: "3-4 cups", item: "neutral oil, for frying" }
    - { amount: "To serve", item: "lemon wedges and Japanese mayonnaise" }
  steps:
    - "Season the chicken with the salt and pepper. Whisk the ginger, garlic, soy sauce, sake and sesame oil in a bowl, add the chicken, mix well and refrigerate 30 minutes."
    - "Heat at least 2.5 cm of oil in a heavy pot to 160°C (325°F)."
    - "Dredge each piece lightly in flour, then in the starch, shaking off the excess each time."
    - "Fry 3-5 pieces at a time for about 90 seconds, until pale golden, then rest on a rack. The heat inside keeps cooking them. Skim out crumbs between batches."
    - "Raise the oil to 180°C (350°F) and fry the rested pieces again for about 45 seconds, until deep golden and crisp. Serve hot with lemon and mayonnaise."
note: "Adapted from Just One Cookbook's karaage (4.77 stars from 421 votes). Needs 30 minutes of marinating on top of the times shown."
