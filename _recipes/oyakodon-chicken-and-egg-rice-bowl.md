---
title: "Oyakodon (Chicken and Egg Rice Bowl)"
date: 2026-11-25
category: Lunch
cuisine: "Japanese"
description: "Chicken and onion simmered in a sweet-savory dashi sauce, set with softly cooked egg and spooned over rice."
image: ""
recipeContent:
  prepTimeMinutes: 15
  cookTimeMinutes: 10
  servingsNumber: 2
  servingsUnit: Bowls
  ingredients:
    - { amount: "1/2", item: "yellow onion, sliced 6 mm thick" }
    - { amount: "10 oz", item: "boneless, skinless chicken thighs" }
    - { amount: "1 tbsp", item: "sake (or dry sherry)" }
    - { amount: "3-4 large", item: "eggs" }
    - { amount: "1/2 cup", item: "dashi" }
    - { amount: "2 tbsp", item: "soy sauce" }
    - { amount: "2 tbsp", item: "mirin" }
    - { amount: "2 tsp", item: "sugar" }
    - { amount: "2 servings", item: "cooked Japanese short-grain rice" }
    - { amount: "4 sprigs", item: "mitsuba or green onions, chopped" }
    - { amount: "To serve", item: "shichimi togarashi (optional)" }
  steps:
    - "Stir the dashi, soy sauce, mirin and sugar together until the sugar dissolves."
    - "Trim the chicken and slice it on an angle into thin bite-size pieces. Toss with the sake and leave 5 minutes."
    - "Crack the eggs into a bowl and break them up with chopsticks just 5-6 times, so whites and yolks stay streaky."
    - "Spread the onion in a medium frying pan and pour in the sauce; it should just cover the onion. Bring to a simmer over medium heat, add the chicken in an even layer, then simmer uncovered on medium-low about 5 minutes, turning once, until the chicken is cooked and the onion soft."
    - "With the sauce gently simmering, drizzle about two-thirds of the egg over the chicken, avoiding the edges. When it starts to set, add the rest, scatter over the mitsuba or green onion, and cook until the egg is as set as you like."
    - "Slide over bowls of hot rice, spoon over the sauce, and add shichimi if you like."
note: "Adapted from Just One Cookbook's oyakodon (4.72 stars from 658 votes). Don't cook more than 2 servings in one pan, or the egg won't set evenly."
