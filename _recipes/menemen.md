  ingredients:
    - { amount: "2 tbsp", item: "extra virgin olive oil, plus more to finish" }
    - { amount: "1", item: "medium yellow onion, chopped" }
    - { amount: "1", item: "green bell pepper, cored, seeded and chopped" }
    - { amount: "To taste", item: "kosher salt" }
    - { amount: "2", item: "vine-ripe tomatoes, chopped" }
    - { amount: "3 tbsp", item: "tomato paste" }
    - { amount: "To taste", item: "black pepper" }
    - { amount: "1/2 tsp", item: "dried oregano" }
    - { amount: "1 tsp", item: "Aleppo pepper, plus more for serving" }
    - { amount: "4", item: "large eggs, beaten" }
    - { amount: "To taste", item: "crushed red pepper flakes (optional)" }
    - { amount: "To serve", item: "thick slices of French baguette" }
  steps:
    - "Heat 2 tbsp oil in a 10-inch skillet over medium heat. Cook the onion and pepper with a pinch of salt 4-5 minutes until soft, without browning."
    - "Add the tomatoes, tomato paste, a little more salt, black pepper, oregano and Aleppo pepper and cook 5-7 minutes until the tomatoes soften but still hold their shape."
    - "Push the mixture to one side and lower the heat to medium-low. Add the eggs and stir gently until just set, then fold in the tomato mixture."
    - "Finish with a drizzle of olive oil, more Aleppo pepper and red pepper flakes for heat. Serve right away with bread."
note: "Adapted from The Mediterranean Dish's menemen (4.91 stars from 87 votes). Take it off the heat while it's still a little soft."
