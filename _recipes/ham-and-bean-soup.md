date: 2026-01-01
category: Soup
cuisine: "American"
description: "A smoky, creamy white bean soup that turns a leftover ham bone into dinner."
image: ""
recipeContent:
  prepTimeMinutes: 20
  cookTimeMinutes: 120
  servingsNumber: 8
  servingsUnit: Bowls
  ingredients:
    - { amount: "1 lb", item: "dried navy or great northern beans" }
    - { amount: "1", item: "ham bone or 2 cups diced ham" }
    - { amount: "1", item: "onion, diced" }
    - { amount: "2", item: "carrots, diced" }
    - { amount: "2", item: "celery stalks, diced" }
    - { amount: "3", item: "garlic cloves, minced" }
    - { amount: "8 cups", item: "chicken broth or water" }
    - { amount: "2", item: "bay leaves" }
    - { amount: "1/2 tsp", item: "black pepper" }
    - { amount: "1 tsp", item: "salt, to taste" }
  steps:
    - "Soak the beans overnight in plenty of water, or do a quick soak: boil 2 minutes, cover, and let sit 1 hour. Drain."
    - "Combine the beans, ham bone, vegetables, garlic, broth, bay leaves and pepper in a large pot."
    - "Bring to a boil, reduce the heat and simmer, partially covered, 1 1/2 to 2 hours until the beans are very tender."
    - "Remove the bone, shred the meat back into the pot, and season with salt. Mash some beans to thicken."
note: "Add salt at the end. Ham is already salty."
