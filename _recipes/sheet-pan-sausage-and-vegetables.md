description: "Smoked sausage with potatoes, peppers and broccoli, roasted on one pan."
image: ""
recipeContent:
  prepTimeMinutes: 15
  cookTimeMinutes: 30
  servingsNumber: 4
  servingsUnit: Servings
  ingredients:
    - { amount: "1 lb", item: "smoked sausage, sliced" }
    - { amount: "1 lb", item: "baby potatoes, halved" }
    - { amount: "2", item: "bell peppers, chopped" }
    - { amount: "1", item: "red onion, cut in wedges" }
    - { amount: "2 cups", item: "broccoli florets" }
    - { amount: "3 tbsp", item: "olive oil" }
    - { amount: "1 tsp", item: "garlic powder" }
    - { amount: "1 tsp", item: "smoked paprika" }
    - { amount: "1 tsp", item: "salt" }
    - { amount: "1/2 tsp", item: "black pepper" }
  steps:
    - "Heat the oven to 425°F. Toss the potatoes with 1 tbsp of oil, half the salt and roast on a large sheet pan for 10 minutes."
    - "Toss the sausage, peppers, onion and broccoli with the remaining oil, garlic powder, paprika, remaining salt and pepper."
    - "Add to the pan, spread in a single layer, and roast 20 minutes, stirring once, until the potatoes are tender and the edges brown."
    - "Serve straight from the pan."
note: "Use two pans rather than crowding one. Crowded vegetables steam instead of browning."
