---
title: "Homemade Cinnamon Rolls"
slug: homemade-cinnamon-rolls
date: 2026-01-01
category: Dessert
cuisine: "American"
description: "Soft, fluffy rolls swirled with cinnamon sugar and topped with cream cheese icing."
image: ""
recipeContent:
  prepTimeMinutes: 30
  cookTimeMinutes: 25
  servingsNumber: 12
  servingsUnit: Rolls
  ingredients:
    - { amount: "1 cup", item: "warm milk" }
    - { amount: "2 1/4 tsp", item: "instant yeast" }
    - { amount: "1/3 cup", item: "granulated sugar" }
    - { amount: "1/3 cup", item: "butter, melted" }
    - { amount: "2", item: "eggs" }
    - { amount: "3 1/2 to 4 cups", item: "all-purpose flour" }
    - { amount: "1 tsp", item: "salt" }
    - { amount: "3/4 cup", item: "packed brown sugar" }
    - { amount: "2 tbsp", item: "ground cinnamon" }
    - { amount: "1/3 cup", item: "butter, softened" }
    - { amount: "4 oz", item: "cream cheese, softened" }
    - { amount: "1/4 cup", item: "butter, softened, for icing" }
    - { amount: "1 1/2 cups", item: "powdered sugar" }
    - { amount: "1 tsp", item: "vanilla extract" }
  steps:
    - "Stir the milk, yeast and 1 tbsp of the sugar and let sit 5 minutes until foamy."
    - "Add the rest of the sugar, melted butter and eggs, then the flour and salt. Knead 8 minutes into a soft, slightly sticky dough. Cover and rise 1 hour until doubled."
    - "Roll into a 16x12-inch rectangle. Spread with the softened butter and sprinkle with brown sugar and cinnamon."
    - "Roll up tightly from the long side and cut into 12 rolls. Place in a greased 9x13 pan, cover and rise 30 minutes."
    - "Bake at 350°F for 20-24 minutes until golden."
    - "Beat the cream cheese, 1/4 cup butter, powdered sugar and vanilla and spread over the warm rolls."
