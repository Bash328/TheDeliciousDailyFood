---
title: "Shepherd's Pie"
slug: shepherds-pie
date: 2026-01-01
category: Dinner
cuisine: "British"
description: "Savory meat and vegetable filling under a blanket of buttery mashed potatoes."
image: ""
recipeContent:
  prepTimeMinutes: 30
  cookTimeMinutes: 45
  servingsNumber: 6
  servingsUnit: Servings
  ingredients:
    - { amount: "2 lbs", item: "russet potatoes, peeled and cubed" }
    - { amount: "4 tbsp", item: "butter" }
    - { amount: "1/2 cup", item: "milk" }
    - { amount: "1 1/2 tsp", item: "salt" }
    - { amount: "1 lb", item: "ground lamb or beef" }
    - { amount: "1", item: "onion, diced" }
    - { amount: "2", item: "carrots, diced" }
    - { amount: "3", item: "garlic cloves, minced" }
    - { amount: "2 tbsp", item: "tomato paste" }
    - { amount: "2 tbsp", item: "all-purpose flour" }
    - { amount: "1 cup", item: "beef broth" }
    - { amount: "1 tbsp", item: "Worcestershire sauce" }
    - { amount: "1 cup", item: "frozen peas" }
  steps:
    - "Boil the potatoes in salted water 15 minutes until tender. Drain, mash with the butter, milk and 1 tsp salt, and set aside."
    - "Heat the oven to 400°F. Brown the meat with the onion and carrots in a large oven-safe skillet, 8-10 minutes. Add the garlic and tomato paste for 1 minute."
    - "Stir in the flour, then the broth and Worcestershire. Simmer 5 minutes until thick. Stir in the peas and remaining salt."
    - "Spread the mashed potatoes over the filling and rough up the top with a fork."
    - "Bake 20-25 minutes until bubbling at the edges and golden on top."
note: "Traditionally shepherd's pie is made with lamb. With beef it's technically a cottage pie."
---
