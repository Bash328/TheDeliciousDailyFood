recipeContent:

  servingsNumber: 6
  servingsUnit: Servings
  ingredients:
    - { amount: "2 lbs", item: "eggplant, cut into 3/4-cm slices" }
    - { amount: "1 tsp", item: "salt, for sweating" }
    - { amount: "2-3 tbsp", item: "olive oil, for brushing" }
    - { amount: "1 tbsp", item: "olive oil, for the meat sauce" }
    - { amount: "1", item: "onion, diced" }
    - { amount: "3", item: "garlic cloves, minced" }
    - { amount: "1.4 lbs", item: "ground beef or lamb" }
    - { amount: "1/2 cup", item: "dry red wine (optional)" }
    - { amount: "14 oz", item: "crushed tomatoes" }
    - { amount: "3 tbsp", item: "tomato paste" }
    - { amount: "1 cup", item: "beef broth" }
    - { amount: "1", item: "beef bouillon cube, crumbled" }
    - { amount: "2", item: "bay leaves" }
    - { amount: "1 1/2 tsp", item: "sugar" }
    - { amount: "2 tsp", item: "dried oregano" }
    - { amount: "1/2 tsp", item: "cinnamon" }
    - { amount: "3/4 tsp", item: "salt, for the meat sauce" }
    - { amount: "4 tbsp (60 g)", item: "butter" }
    - { amount: "5 tbsp", item: "all-purpose flour" }
    - { amount: "2 1/2 cups", item: "milk" }
    - { amount: "1/4 tsp", item: "freshly grated nutmeg (optional)" }
    - { amount: "1/2 cup", item: "grated Parmesan or kefalotiri" }
    - { amount: "1", item: "egg" }
    - { amount: "1", item: "egg yolk" }
    - { amount: "1 1/4 tsp", item: "vegetable or chicken stock powder (or salt)" }
    - { amount: "1/4 tsp", item: "pepper" }
    - { amount: "1/3 cup", item: "panko breadcrumbs" }
  steps:
    - "Layer the eggplant slices in a colander, sprinkle with salt and leave to sweat 30 minutes. Meanwhile, make the meat sauce and béchamel."
    - "Heat the oven to 450°F. Pat the eggplant very dry, lay it on parchment-lined trays, brush with oil and bake 15-20 minutes until lightly browned and softened."
    - "For the meat sauce, cook the onion and garlic in 1 tbsp oil 2 minutes. Add the meat and cook until it loses its pink color, breaking it up. Add the wine and cook 1 1/2 minutes."
    - "Add the tomatoes, paste, broth, bouillon, bay leaves, sugar, oregano, cinnamon and salt. Simmer on medium-low about 15 minutes until thick."
    - "For the béchamel, melt the butter, stir in the flour for 1 minute, then slowly add the milk and stir 3-5 minutes until it thickly coats a spoon. Off the heat, whisk in the cheese, nutmeg, stock powder and pepper. Cool 5 minutes, then whisk in the egg and yolk."
    - "Lower the oven to 350°F. Put half the eggplant in a baking dish, top with all the meat sauce, then the rest of the eggplant."
    - "Pour over the béchamel and sprinkle with panko. Bake 30-40 minutes until golden brown, then rest 10 minutes before serving."
note: "Adapted from RecipeTin Eats' moussaka (4.94 stars from 313 votes). Patting the sweated eggplant dry keeps it from being too salty."
