cuisine: "American"
description: "Salmon fillets brushed with a lemon, garlic, Dijon and parsley mix and baked hot. Twenty minutes from start to table."
image: ""
recipeContent:
  prepTimeMinutes: 5
  cookTimeMinutes: 15
  servingsNumber: 4
  servingsUnit: Servings
  ingredients:
    - { amount: "1 1/2 lb", item: "salmon fillet, cut into 4 pieces" }
    - { amount: "2 tbsp", item: "fresh parsley, finely chopped" }
    - { amount: "2 tbsp", item: "light olive oil or vegetable oil" }
    - { amount: "2 tbsp", item: "fresh lemon juice" }
    - { amount: "3", item: "garlic cloves, minced" }
    - { amount: "1/2 tbsp", item: "Dijon mustard" }
    - { amount: "1/2 tsp", item: "fine sea salt" }
    - { amount: "1/8 tsp", item: "black pepper" }
    - { amount: "1/2", item: "lemon, sliced into 4 rounds" }
  steps:
    - "Heat the oven to 230°C / 450°F and line a rimmed baking sheet. Lay the salmon on it skin-side down."
    - "Stir the parsley, garlic, oil, lemon juice, mustard, salt and pepper together."
    - "Brush it generously over the tops and sides of the salmon and put a lemon slice on each piece."
    - "Bake uncovered 12-15 minutes, just until the salmon flakes and reaches 63°C (145°F) in the thickest part. Don't overcook it."
note: "Adapted from Natasha's Kitchen's baked salmon (4.98 stars from 1,208 votes)."
