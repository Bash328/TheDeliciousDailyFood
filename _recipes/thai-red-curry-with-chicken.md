---
title: "Thai Red Curry with Chicken"
date: 2026-11-25
category: Dinner
cuisine: "Thai"
description: "Chicken, pumpkin and green beans simmered in a rich coconut red curry with lime leaves and Thai basil."
image: ""
recipeContent:
  prepTimeMinutes: 5
  cookTimeMinutes: 20
  servingsNumber: 4
  servingsUnit: Servings
  ingredients:
    - { amount: "3 tbsp", item: "vegetable oil" }
    - { amount: "5-6 tbsp", item: "Thai red curry paste (Maesri is a good brand)" }
    - { amount: "2 large", item: "garlic cloves, minced" }
    - { amount: "2 tsp", item: "fresh ginger, finely grated" }
    - { amount: "1 tbsp", item: "lemongrass paste or finely chopped fresh lemongrass" }
    - { amount: "1 cup (250 ml)", item: "low-sodium chicken broth" }
    - { amount: "400 ml (14 oz)", item: "full-fat coconut milk" }
    - { amount: "6", item: "kaffir lime leaves" }
    - { amount: "1 tbsp", item: "sugar (white, brown or palm)" }
    - { amount: "2 tsp", item: "fish sauce, plus more to taste" }
    - { amount: "350 g (12 oz)", item: "boneless, skinless chicken thighs, thinly sliced" }
    - { amount: "150 g (5 oz)", item: "pumpkin or butternut squash, cut into 1.5 cm cubes" }
    - { amount: "120 g (4 oz)", item: "green beans, cut into 5 cm pieces" }
    - { amount: "12", item: "Thai basil leaves" }
    - { amount: "To serve", item: "sliced red chili, cilantro and jasmine rice" }
  steps:
    - "Heat the oil in a large heavy skillet over medium-high heat. Add the curry paste with the garlic, ginger and lemongrass and fry for about 2 minutes, until it darkens and smells toasty."
    - "Stir in the broth to dissolve the paste and boil hard for 3 minutes, until reduced by half."
    - "Add the coconut milk, lime leaves, sugar and fish sauce, then the chicken. Bring to a simmer, turn down to medium and cook 8-10 minutes, until the chicken is done and the sauce has thickened."
    - "Taste and add more fish sauce for salt or sugar for sweetness."
    - "Add the pumpkin and beans and cook about 3 minutes, until the pumpkin is just tender."
    - "Take off the heat, stir in the basil, and serve over rice with chili and cilantro."
note: "Adapted from RecipeTin Eats' Thai red curry with chicken (4.94 stars from 359 votes). Jarred paste plus garlic, ginger and lemongrass tastes close to homemade."
