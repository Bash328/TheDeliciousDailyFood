tag: "One Pan"
description: "Seared salmon finished in a paprika-spiced tomato cream sauce with lemon and fresh oregano."
image: "creamy-tomato-salmon.jpg"
recipeContent:
  prepTimeMinutes: 10
  cookTimeMinutes: 20
  servingsNumber: 2
  servingsUnit: Servings
  ingredients:
    - { amount: "2", item: "salmon fillets, skin removed" }
    - { amount: "1/2 tsp", item: "salt" }
    - { amount: "1/2 tsp", item: "smoked paprika" }
    - { amount: "1 tbsp", item: "olive oil" }
    - { amount: "3", item: "garlic cloves, minced" }
    - { amount: "3 tbsp", item: "tomato paste" }
    - { amount: "3/4 cup", item: "heavy cream" }
    - { amount: "1/4 cup", item: "chicken broth" }
    - { amount: "1/2", item: "lemon, sliced, plus more for serving" }
    - { amount: "2 tbsp", item: "fresh oregano, chopped" }
  steps:
    - "Season the salmon with salt and smoked paprika. Heat olive oil in a skillet over medium-high heat and sear the salmon 3-4 minutes per side, until just cooked through. Remove and set aside."
    - "Lower the heat, add garlic to the same pan, and cook 30 seconds until fragrant."
    - "Stir in the tomato paste and cook a minute to deepen its color, then whisk in the cream and chicken broth. Simmer 3-4 minutes until slightly thickened."
    - "Return the salmon to the pan, nestling in the lemon slices, and spoon the sauce over the top. Simmer 2 minutes more to warm through."
    - "Scatter with fresh oregano and serve straight from the pan."
note: "The sauce is rich enough to serve over pasta or rice if you want to stretch it into a full plate."
