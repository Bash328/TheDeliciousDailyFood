description: "Chewy rice cakes simmered in a sweet, spicy gochujang sauce on an anchovy-kelp stock."
image: ""
recipeContent:
  prepTimeMinutes: 10
  cookTimeMinutes: 30
  servingsNumber: 4
  servingsUnit: Servings
  ingredients:
    - { amount: "1 lb (450 g)", item: "cylinder-shaped rice cakes (tteok), fresh or frozen" }
    - { amount: "4 cups", item: "water" }
    - { amount: "7", item: "large dried anchovies, heads and guts removed" }
    - { amount: "One 6 x 8-inch", item: "piece dried kelp" }
    - { amount: "1/3 cup", item: "gochujang (hot pepper paste)" }
    - { amount: "1 tbsp", item: "gochugaru (Korean red chili flakes)" }
    - { amount: "1 tbsp", item: "sugar" }
    - { amount: "3", item: "green onions, cut into 3-inch pieces" }
    - { amount: "2", item: "hard-boiled eggs, shelled (optional)" }
    - { amount: "1/2 lb", item: "fish cakes, cut into bite-sized pieces (optional)" }
  steps:
    - "If the rice cakes are frozen, thaw and soak them in cold water to soften."
    - "Put the water, anchovies and kelp in a shallow pot and boil uncovered over medium-high heat for 15 minutes."
    - "Mix the gochujang, gochugaru and sugar in a small bowl."
    - "Remove the anchovies and kelp. You should have about 2 1/2 cups of stock, so top up with water if needed."
    - "Add the rice cakes, the spicy mixture, the green onions and the optional fish cakes and eggs. When it boils, stir gently and keep stirring as it simmers 10-15 minutes until the rice cakes are soft and the sauce is thick and shiny. Add a little water if they're not soft enough."
    - "Serve hot, right away. They're best fresh."
