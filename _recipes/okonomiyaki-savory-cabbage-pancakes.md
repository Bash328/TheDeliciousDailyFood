recipeContent:

  cookTimeMinutes: 25
  servingsNumber: 4
  servingsUnit: Pancakes
  ingredients:
    - { amount: "1 cup", item: "all-purpose flour" }
    - { amount: "1/4 tsp", item: "kosher salt" }
    - { amount: "1/4 tsp", item: "sugar" }
    - { amount: "1/4 tsp", item: "baking powder" }
    - { amount: "5.6 oz", item: "nagaimo (mountain yam), grated" }
    - { amount: "3/4 cup", item: "dashi" }
    - { amount: "1/2 head", item: "green cabbage (about 1.4 lb), minced" }
    - { amount: "1/4 cup", item: "pickled red ginger, chopped" }
    - { amount: "1/2 lb", item: "thinly sliced pork belly, cut into 4-inch pieces" }
    - { amount: "4", item: "large eggs" }
    - { amount: "1/2 cup", item: "tenkasu (tempura scraps)" }
    - { amount: "For cooking", item: "neutral oil" }
    - { amount: "3 tbsp", item: "sugar, for the sauce" }
    - { amount: "1/4 cup", item: "oyster sauce" }
    - { amount: "1/2 cup", item: "ketchup" }
    - { amount: "7 tbsp", item: "Worcestershire sauce" }
    - { amount: "To top", item: "Japanese mayonnaise, katsuobushi, aonori and chopped green onion" }
  steps:
    - "If you have time, rest the batter: mix the flour, salt, sugar and baking powder, stir in the grated nagaimo and dashi, and chill at least 1 hour (up to overnight) for a fluffier pancake. Nagaimo can irritate skin, so rinse your hands right after grating."
    - "Mince the cabbage and drain it well so it doesn't water down the batter."
    - "Add the eggs, tenkasu and two-thirds of the pickled ginger to the batter and mix. Fold in the cabbage a third at a time, until it's well coated."
    - "Heat a little oil in a large griddle or two lidded frying pans on medium heat (about 400°F). Spoon in the batter and shape into 6-inch rounds about 3/4 inch thick."
    - "Lay 3 slices of pork belly on each and cook, covered, on medium-low for 5 minutes. Flip, press gently to shape, and cook covered 5 minutes more. Flip once more and cook uncovered 2 minutes."
    - "Mix the sugar, oyster sauce, ketchup and Worcestershire for the sauce until the sugar dissolves."
    - "Brush the sauce on top, drizzle mayonnaise in a zigzag, and finish with katsuobushi, aonori, green onion and the remaining ginger."
note: "Adapted from Just One Cookbook's okonomiyaki (4.74 stars from 728 votes). Nagaimo is the secret to a fluffy pancake; look for it in Asian markets."
