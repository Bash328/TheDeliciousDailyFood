title: "Chicken Alfredo"
slug: chicken-alfredo
date: 2026-01-01
category: Dinner
tag: "Classic"
description: "Fettuccine in a silky garlic Parmesan cream sauce with sliced chicken."
image: ""
recipeContent:
  prepTimeMinutes: 10
  cookTimeMinutes: 25
  servingsNumber: 4
  servingsUnit: Servings
  ingredients:
    - { amount: "2", item: "chicken breasts, sliced in half" }
    - { amount: "1 tsp", item: "salt" }
    - { amount: "1/2 tsp", item: "black pepper" }
    - { amount: "2 tbsp", item: "olive oil" }
    - { amount: "12 oz", item: "fettuccine" }
    - { amount: "4 tbsp", item: "butter" }
    - { amount: "4", item: "garlic cloves, minced" }
    - { amount: "1 1/2 cups", item: "heavy cream" }
    - { amount: "1 1/2 cups", item: "grated Parmesan" }
    - { amount: "To serve", item: "fresh parsley, chopped" }
  steps:
    - "Season the chicken with salt and pepper. Cook in the oil in a large skillet over medium-high heat, 5-6 minutes per side until 165°F. Rest, then slice."
    - "Cook the fettuccine in salted water until al dente. Reserve 1/2 cup of the pasta water, then drain."
    - "In the same skillet, melt the butter and cook the garlic 30 seconds. Add the cream and simmer 3 minutes."
    - "Stir in the Parmesan until smooth. Toss in the pasta, adding pasta water a splash at a time to loosen the sauce."
    - "Top with the sliced chicken and parsley."
note: "Serve right away. Alfredo sauce thickens fast as it cools."
