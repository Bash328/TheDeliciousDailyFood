---
title: "Lemon Blueberry Muffins"
date: 2026-11-25
category: Breakfast
cuisine: "American"
description: "Tall, fluffy lemon muffins packed with blueberries under a buttery lemon crumb topping."
image: ""
recipeContent:
  prepTimeMinutes: 20
  cookTimeMinutes: 23
  servingsNumber: 12
  servingsUnit: Muffins
  ingredients:
    - { amount: "1 3/4 cups (219 g)", item: "all-purpose flour" }
    - { amount: "1 tsp", item: "baking soda" }
    - { amount: "1 tsp", item: "baking powder" }
    - { amount: "1/2 tsp", item: "salt" }
    - { amount: "6 tbsp (85 g)", item: "unsalted butter, softened" }
    - { amount: "3/4 cup (150 g)", item: "granulated sugar" }
    - { amount: "1 tbsp", item: "lemon zest" }
    - { amount: "2 large", item: "eggs, at room temperature" }
    - { amount: "1/2 cup (120 g)", item: "plain Greek yogurt or sour cream" }
    - { amount: "1 1/2 tsp", item: "vanilla extract" }
    - { amount: "3 tbsp", item: "milk" }
    - { amount: "3 tbsp", item: "fresh lemon juice" }
    - { amount: "1 1/2 cups (210 g)", item: "fresh or frozen blueberries, tossed in 1 tbsp flour" }
    - { amount: "1/3 cup (41 g)", item: "all-purpose flour, for the crumb" }
    - { amount: "2 tbsp", item: "packed brown sugar" }
    - { amount: "1 tsp", item: "lemon zest, for the crumb" }
    - { amount: "2 tbsp", item: "unsalted butter, melted, for the crumb" }
  steps:
    - "Heat the oven to 220°C / 425°F and grease or line a 12-cup muffin pan."
    - "Whisk the flour, baking soda, baking powder and salt together."
    - "Beat the butter and sugar until creamy, about 3 minutes. Beat in the lemon zest for a minute, then the eggs, yogurt and vanilla. It may look curdled; that's fine."
    - "On low speed, add the dry ingredients, milk and lemon juice and mix until no flour pockets remain. Fold in the blueberries gently."
    - "Fill the muffin cups right to the top. Mix the crumb ingredients with a fork and press a little onto each."
    - "Bake 5 minutes at 220°C, then, without opening the door, lower to 180°C / 350°F and bake 18-19 minutes more, until a toothpick comes out clean. Cool 5 minutes in the pan, then on a rack."
note: "Adapted from Sally's Baking Addiction's lemon blueberry muffins (4.7 stars from 184 votes). The hot start is what gives them tall domes."
---
