cuisine: "Japanese"
description: "Thin-sliced beef and onions simmered in a sweet-savory dashi sauce over rice, ready in 20 minutes."
image: ""
recipeContent:
  prepTimeMinutes: 5
  cookTimeMinutes: 15
  servingsNumber: 2
  servingsUnit: Bowls
  ingredients:
    - { amount: "1/2 lb", item: "thinly sliced beef (ribeye or chuck)" }
    - { amount: "1/2", item: "yellow onion, thinly sliced" }
    - { amount: "1", item: "green onion, sliced diagonally" }
    - { amount: "1/2 cup", item: "dashi (Japanese soup stock)" }
    - { amount: "2 tbsp", item: "sake" }
    - { amount: "2 tbsp", item: "mirin" }
    - { amount: "3 tbsp", item: "soy sauce" }
    - { amount: "1 tbsp", item: "sugar, to taste" }
    - { amount: "2 servings", item: "cooked Japanese short-grain rice" }
    - { amount: "To serve", item: "pickled red ginger" }
  steps:
    - "Freeze the sliced beef for 10 minutes if it needs cutting, and cut it into 3-inch pieces."
    - "Start with a large cold frying pan. Add the dashi, sake, mirin, soy sauce and sugar and stir to dissolve the sugar."
    - "Separate the onion layers into the cold broth, then lay the beef slices on top of the onions."
    - "Cover and turn the heat to medium. Once it simmers, lower the heat and cook, covered, 3-4 minutes, skimming off any scum or fat once or twice."
    - "Scatter over the green onion and cook covered 1 more minute (beaten egg can go in now, if you like)."
    - "Divide the rice between two bowls, drizzle with some of the pan sauce, and top with the beef and onions and extra sauce. Finish with pickled red ginger."
note: "Adapted from Just One Cookbook's gyudon (4.74 stars from 538 votes). Starting in a cold pan keeps the beef tender."
