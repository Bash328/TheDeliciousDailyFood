---
title: "Salisbury Steak"
slug: salisbury-steak
date: 2026-01-01
category: Dinner
tag: "Classic"
description: "Seasoned beef patties smothered in mushroom onion gravy."
image: ""
recipeContent:
  prepTimeMinutes: 15
  cookTimeMinutes: 25
  servingsNumber: 4
  servingsUnit: Servings
  ingredients:
    - { amount: "1 1/2 lbs", item: "ground beef" }
    - { amount: "1/3 cup", item: "breadcrumbs" }
    - { amount: "1", item: "egg" }
    - { amount: "1 tbsp", item: "Worcestershire sauce" }
    - { amount: "1 tsp", item: "salt" }
    - { amount: "1/2 tsp", item: "black pepper" }
    - { amount: "2 tbsp", item: "vegetable oil" }
    - { amount: "8 oz", item: "mushrooms, sliced" }
    - { amount: "1", item: "onion, sliced" }
    - { amount: "2 tbsp", item: "all-purpose flour" }
    - { amount: "2 cups", item: "beef broth" }
    - { amount: "1 tbsp", item: "Dijon mustard" }
  steps:
    - "Mix the beef, breadcrumbs, egg, Worcestershire, salt and pepper. Shape into 4 oval patties."
    - "Brown the patties in the oil in a large skillet over medium-high heat, 3 minutes per side. Remove."
    - "Cook the mushrooms and onion in the pan 8 minutes until golden. Sprinkle in the flour and stir 1 minute."
    - "Whisk in the broth and mustard and bring to a simmer, scraping up the browned bits."
    - "Return the patties to the pan, cover and simmer 10 minutes until cooked through."
    - "Serve with mashed potatoes."
